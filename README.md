# ECR-NeuroMemory

**ECR（Executable Cognitive Runtime）理论档案与 AI 长期记忆研究实验入口。**

这个公开仓库首先保存已有的 ECR 研究原稿，而不是宣布已经实现“数字生命”。核心研究问题是：**个人经历及其形成的关联与认识，能否在长期交互、上下文压缩和跨会话后，持续改变 Agent 的记忆浮现、理解与选择？**

## 研究边界

- 当前文档包含**原始理论、研究假设、工程断言和待验证建议**，不表示对应机制已完成实现。
- 类神经元是工程运行机制假设，不声称与生物神经元等价；“人格”或“数字生命”不构成主观意识的证据。
- 可参考 DSH 等 Agent 框架探索长期记忆接入，但现阶段**没有已验收的 DSH 插件或性能改进结果**。
- 历史 Markdown 正文保留原貌；未来若修改观点，应以新文件/明确版本附注，不暗改旧稿。
- 引用文档内的旧项目路径、研究记录和任务名称，未必表示该文件也收录在本仓库；本次是**有范围的十篇归档**。

## 给开发 Agent：最小使用规则

1. 先读 `theory/01-foundations/`，确认 ECR 定义、LLM/记忆引擎职责边界。
2. 根据研究任务从 `theory/02-memory-mechanisms/` 定向读取，不要每轮塞入全部文档。
3. 进行长期记忆插件研究时，优先处理原始事件的**来源与可回溯性、多入口关联、动态激活与工作集、有依据的认识修订**。
4. 不把摘要复述、RAG 检索命中、预编台词或 LLM 角色扮演当作“自主认知网络已实现”。
5. 对比实验应包含摘要/普通检索基线、相同模型与上下文预算、跨会话或压缩后保持与修订的测试。
6. 不擅自扩大成完整 ECR 重构。遇到前后原稿冲突时，保留日期、来源和旧观点，另写裁决文件。
7. 任何性能、兼容性、连续认知或人格相关结论，都必须区分**目标、机制假设、测试结果及已知限制**。
