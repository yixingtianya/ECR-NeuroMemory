# ECR 科研任务书 v1.0｜研究主线恢复版

**日期：2026-10-04**  
**性质：科研总任务书 / 研究约束文件**  
**作用：高于单个工程 TASK、RESULT 与接口实现计划；用于回答“ECR 到底要证明什么、怎样算科研进展、工程工作为何值得做”。**  
**不是：**新架构版本、模块设计书、代码实施计划、产品路线图、完成度宣言。

---

## 0. 研究总命题

ECR（Executable Cognitive Runtime）的总研究命题是：

> **在认知引擎与底层语言模型基本保持不变的条件下，个人经历以及由这些经历形成的认识，能否持续改变系统的注意、联想、理解、判断、选择与表达；这些认识能否在新经历、新证据和反例出现后发生有来源、可追溯、可修订的演化，并最终形成稳定但非僵死的个体差异。**

最终目标不是“角色说话像谁”，也不是“记忆越多回答越像有过去”，而是检验：

> **角色是否因为拥有不同的过去，而形成不同的现在。**

因此，ECR 的核心科研对象不是某个 Runtime 接口，而是**认知网络的形成、运行、演化与长期个体化**。

---

# 1. 研究对象与边界

## 1.1 研究对象

ECR 研究四个彼此耦合的问题：

1. **认知网络怎样形成？**  
   原始经历如何经过结构化、事件组装、有限推演和关系连接，成为可多入口进入、可继续生长的个人认知网络，而不是孤立文本或向量记录。

2. **认知网络怎样在当下运行？**  
   当前刺激、目标、已有认识、人物关系和历史经验如何共同改变激活、访问、竞争与工作认知，使不同内容在不同处境中浮现。

3. **认识怎样产生、竞争、偏移、修订并重新解释过去？**  
   中间认识如何继续参与下一层推演；多套解释如何共存、交织、相互影响；新证据如何改变旧认识而不抹除认识历史。

4. **长期运行是否产生可迁移、可修订的个体差异？**  
   经历是否逐渐形成 schema、belief、self-model、人物认识、习惯与偏向，并在未见的新情境中稳定影响理解和选择；反例是否能够修订这些结构。

## 1.2 非研究结论

以下情况不能被直接提升为 ECR 核心理论的成功证据：

- 某个接口、数据结构或状态账本通过软件测试；
- 检索命中了相关记忆；
- 一个 source 被撤回后 adopted 退出；
- LLM 输出了合法 JSON / stance / proposal；
- 人工给定正确 TaskSpec、候选关系或语义 oracle 后系统能继续运行；
- 台词更像角色、回答更流畅、记忆引用更多；
- 代码覆盖率、测试数量、token 数或文件数量增加。

这些可以是**实验仪器或机制基础设施证据**，但不能替代目标认知现象本身。

# 2. 核心理论在科研中的位置

本节不把项目术语重新定义为模块，而是说明它们分别承担什么科研解释任务。

## 2.1 何乐礼 / 打孔卡：认知零件如何变得可计算

研究主张：自然语言经历需要被拆成有位置、有身份、有来源、可连接的结构单元，使稳定的机械工作由机器承担，而不是让 LLM 反复维护自己的“脑内账务”。

科研问题不是“字段有没有”，而是：

> **这种不提前写入最终推理答案的结构表示，是否真正改善后续关系理解、状态跟踪、组合、修订与迁移。**

现有 H-IR（Cognition IR）与 H-MARKER 属于该方向的可检验子假说。

## 2.2 拼图 / 记忆组装：经历如何成为认知网络

一段经历进入系统后，不应只成为可搜索文本，而应逐步形成：事件结构、明确关系、明确感受与认识、有限派生关系、跨经历连接以及多个可再次进入的位置。

“出口”和“入口”是同一认知接口的两个方向：从记忆内部看，它是未来可流出的出口；从当前认知看，它是重新进入旧网络的入口。

核心假说：

> **经过有依据的组装与有限侦探推演形成的多入口记忆网络，比孤立文本/向量记录更能支持后续的关联、重解释、迁移与个体化认知。**

## 2.3 类神经元 / 弹窗：此刻为什么会想到这些

研究主张：当前刺激不应只触发固定 top-k，相同长期记忆在不同目标、人物关系、当前认识和近期状态下，应形成不同的局部激活与工作认知。

核心对象包括激活、传播、竞争、抑制、衰减和有限工作区；“检索命中”只是可能的实现信号，不等于认知浮现已经成立。

## 2.4 侦探理论：认识如何继续产生认识

侦探理论不是单次“找资料”，也不只属于意识层。它贯穿：

- **记忆形成：**在事件内部和跨事件之间发现有价值的关系，形成派生认识与未来入口；
- **在线认知：**当前材料与旧认识组合形成中间认识，中间认识继续参与下一层组合；
- **调查反馈：**假说、缺口、疑问改变后续取证方向，新材料再改变解释；
- **记忆重组：**新证据与旧认识重新组合，形成对旧经历的新解释。

核心科研命题：

> **A 与 B 能否形成新的 C；C 是否能作为真正的内容与前提继续和 D/E 组合产生新的认识，而不只是成为检索关键词；这些中间认识是否能反过来改变未来访问与解释。**

## 2.5 蓝鲸理论：多套认识怎样共同生长

蓝鲸理论不等于 source withdraw 或布尔真假切换。它研究：

- 多个解释与假说怎样共存；
- 为什么主体可能暂信、怀疑、固执、偏向或改变；
- 独立来源、传播链、来源可靠性、内容先验与已有认识怎样影响采用；
- 某个错误认识如何继续影响注意与召回；
- 新证据如何使旧认识获得新的历史意义；
- 不同解释树如何共享观察、交叉、竞争甚至生成新的认识。

“撤回”只是一项底层资格变化操作；真正的蓝鲸研究对象是**认知森林的竞争、交织与演化**。

## 2.6 聚沙成塔：长期发展性总假说

聚沙成塔不是一个独立模块，而是纵向问题：

> **上述机制长期运行以后，这张认知网络会长成什么？**

需要检验的长期产物包括：

- schema / belief / self-model；
- 对具体人物和关系的长期认识；
- 习惯、偏见、原则、稳定关注方式；
- 对过去错误的元认知；
- 在未见新场景中的迁移；
- 遭遇反例后的收缩、修订和重组。

## 2.7 人物认识 / 标签理论

人物认识不是表达风格标签，而是主体关于“对方是谁、与我是什么关系、他知道什么、需要什么、过去发生过什么”的可修订认识。

科研问题是：

> **这些人物认识是否在表达之前就影响注意、联想、解释与选择，而不是最后附加一个 style prompt。**

## 2.8 E / F：内部认知差异怎样进入行为

E（选择）与 F（表达）主要承担观察窗口：内部认知差异是否真的进入行动选择和实际表达。

它们不是人格来源，也不能反过来用漂亮台词证明前面的认知机制成立。

# 3. 核心科研问题（Research Questions）

## RQ-A｜表示是否有独立认知收益？

在事实内容、模型、采样和任务保持一致时，结构化意义表示是否比 Raw / Flat 表示更有利于：状态跟踪、嵌套关系、关系桥梁、缺失中间链和反馈循环处理？

必须区分结构收益与人工显式补答案、字段名提示、token 增量等混杂因素。

## RQ-B｜经历能否形成真正的多入口认知网络？

同一组经历，如果只按文本/向量保存，与经过事件组装、明确关系连接、有限侦探推演和入口构造相比，后续关联、重解释、迁移和召回是否出现可重复差异？

## RQ-C｜当前处境是否能改变认知网络的激活方式？

在长期记忆不变时，仅改变当前目标、人物关系、当前认识或近期状态，系统浮现的材料、竞争路径和工作认知是否系统改变？这些变化是否超出简单关键词/top-k解释？

## RQ-D｜中间认识是否能递归参与下一层思考？

能否观察到：A+B→C，且 C 以有身份、有前提的认识参与 C+D→E；改变 C 的内容或支撑时，E 按理论预期变化；无关变化不应扰动 E。

## RQ-E｜假说是否会改变调查并被新材料反向修订？

假说、缺口和疑问是否真实改变后续取证方向；新材料是否能改变解释并触发新的调查，而不是预先写好 q2 或固定查询脚本。

## RQ-F｜蓝鲸式多解释网络是否产生真实的采用动力？

在同一材料下，独立来源、来源可信度、传播深度、已有认识、反证与重复同源出现等因素，是否会造成可解释的采用差异；旧分支是否保留历史并能参与后续重解释，而不是简单删除。

## RQ-G｜认识历史能否形成元认知？

例如“我曾怀疑他”＋“后来找到斧头”＋“旧解释失去支撑”，能否产生“我可能误会了／我当时存在先入为主”的新认识；该认识能否进一步影响以后对相似事件的判断。

## RQ-H｜长期经历是否形成可迁移、可修订的个体差异？

在同一引擎、同一模型、同一初始条件下，仅改变人生经历，经过一段受控历程后，两个主体在未见场景中的注意、解释、选择是否稳定分化；删除关键经历时差异是否减弱；加入反例时是否能修订而不是换一句总结。

# 4. 证据等级：以后“通过”必须说明通过了哪一级

## E0｜工程存在性

接口、数据结构、来源、状态、版本、依赖、工作区等可以正确运行。

**不能说明认知机制成立。**

## E1｜机制可执行性

在人工正确结构、候选或规则条件下，机制真实执行了预定操作，并产生可追踪状态变化。

**说明机制能够运行，不说明系统能自主形成其输入。**

## E2｜因果机制证据

只改变理论认为关键的变量，结果按预注册预测改变；无关变量或负控不产生同样变化，并排除了明显替代解释。

这是核心科研机制开始得到支持的最低等级。

## E3｜迁移与组合证据

机制在换人物、换表面题材、换关系组合、未见 held-out 场景后仍成立，并且不是依赖固定词面、固定人物或针对案例写死的规则。

## E4｜纵向发展证据

不同经历历史在相同引擎中产生稳定可解释的长期差异；差异可追溯到历史，能迁移到新情境，并在反例出现后发生有依据的修订。

只有进入 E4，才能开始严肃讨论“经历驱动的人格形成”。

# 5. 当前科研基线（2026-10-04）

以下只记录目前能够支持的最窄结论。

## 5.1 已有有限正证据

- 在受限结构化环境中，经历/记忆可以改变后续预测、行动或候选状态；这说明“过去能够参与计算”不是纯设想。
- 固定候选与人工条件下，有界反馈可以继续取证、处理反证、保留独立支持并停止；说明一部分侦探式机械控制可以执行。
- 当前认识的结构可以在人工正确条件下改变后续访问；说明“认识影响下一次访问”已有局部机制信号。
- 主观新内容的身份、来源、依赖、当前效力、历史保留与有限再访问已有工程接收路径。

## 5.2 重要负结果 / 未获支持

- 当前组合签名装置没有独立访问贡献，不能作为“熟悉关系模式自动唤起经验”的证据。
- 早期真实主体调查没有展示主动补证；不能称自主侦探闭环成立。
- GAP-04 的材料意义差异未被稳定展示，开放语义理解仍不足。
- 自然主体新认识回程实验没有形成可接受的新理解，并出现转述关系保真失败。
- 当前 canonical 主线尚无 H1 内容真正参与并生成 H2 的证据。

## 5.3 主要尚未验证的核心理论

- H-IR 的独立认知收益；
- 自动记忆建网与多入口形成；
- 动态传播、竞争、抑制、衰减；
- 开放的递归侦探推演；
- 蓝鲸式主体采用动力与森林式重解释；
- schema / belief / self-model 的开放形成；
- 人物认识对注意、理解和选择的因果影响；
- 超上下文人生记忆；
- 同引擎不同人生造成的纵向人格分化；
- 自主 E 选择与长期自然 F 表达。

因此，**当前阶段不是“设计收尾期”，而是“已经具备部分实验仪器，开始能够严肃验证核心认知假说”的阶段。**

# 6. 研究方法总则

## 6.1 理论问题先于工程断点

每个新研究任务必须先回答：

1. 要检验哪条认知主张？
2. 最强的替代解释是什么？
3. 操纵哪个变量？
4. 预期哪些结果会变化、哪些不应变化？
5. 现有工程仪器够不够？不够才增加实现。
6. 最终最多能把证据提高到 E0–E4 哪一级？

不得因为“这里刚好有一个没接的 consumer”就自动成为科研主线。

## 6.2 因果干预优先于相关观察

优先使用：消融、反事实、同材料不同结构、同引擎不同历史、独立来源 vs 同源重复、相关变量 vs 无关变量、反例注入、来源撤销与恢复等设计。

“看起来合理”不能替代干预证据。

## 6.3 理论变量与工程代理变量分开

必须显式防止以下构念替代：

- 检索命中 ≠ 浮现；
- B返回数量 ≠ 联想质量；
- source撤回 ≠ 蓝鲸修订；
- adopted退出 ≠ 信念改变已经解释；
- JSON合法 ≠ 新理解；
- H1端点变成cue ≠ H1内容参与H2推演；
- 有人物标签 ≠ 人物认识形成；
- 风格变化 ≠ 人格形成。

## 6.4 FIRST FAIL 只约束受污染执行链

FIRST FAIL 用于定位一条自动链最早可观察错误，防止下游成绩被污染。

它不能回答“下一项科研最值得研究什么”，也不能阻断使用人工正确结构进行独立内核机制实验。

## 6.5 负结果必须保留

若某装置不能区分理论条件、没有独立贡献、或只是在代码上存在，必须保留其失败身份；不能加权、补提示、扩大定义后重新包装为理论成功。

## 6.6 人工贡献、机器贡献、主体贡献必须分账

人工给出的候选、规则、TaskSpec、semantic oracle、curated记忆都必须保留身份，不能被运行结果洗成“系统自主形成”。

# 7. 研究任务群

这些是科研问题群，不是必须严格串行的工程阶段。

## Task A｜表示与认知零件

目标：检验 H-IR / 打孔卡结构是否带来独立认知收益。

核心结果不是 Parser 分数，而是相同 reasoner 在 Raw / Flat / Structured 条件下的关系理解、状态跟踪和中间链差异。

## Task B｜记忆建网与多入口形成

目标：检验经历从“资料”变成“可使用认知网络”的过程。

重点比较孤立存储与事件组装＋明确关系＋有限侦探推演＋多入口网络，观察后续关联、重解释与迁移是否产生独立收益。

## Task C｜动态激活与弹窗

目标：检验同一长期记忆在不同当前目标、关系和认识下是否形成不同的局部工作认知，并排除简单关键词/top-k解释。

## Task D｜递归侦探与调查反馈

目标：检验 A+B→C、C+D→E 的内容级递归，以及假说/缺口对后续取证的真实影响。

**当前 H1→H2 续算属于 Task D 的一个高信息量子实验，不是整个 ECR 主线。**

## Task E｜蓝鲸式竞争、偏见与重解释

目标：检验多解释共存、独立支持、来源可信度、同源重复、反证、采用历史以及“对旧认识的新认识”。

## Task F｜长期聚沙成塔

目标：让若干机制在受控人生历程中长期运行，检验 schema / belief / self-model、人物认识和习惯是否形成，并能迁移和修订。

## Task G｜人格与行为结果

目标：在同引擎不同人生的受控纵向实验中，检验未见新情境的注意、理解、选择和表达是否稳定分化，并通过历史消融确认因果来源。

# 8. 当前优先级原则

下一实验不按“代码离完成最近”排序，而按三项共同决定：

1. **理论基础性：**若为真/假，会改变多少后续研究？
2. **可归因性：**能否用干净干预区分理论效应与提示、词面、人工答案、检索数量等替代解释？
3. **实验准备度：**现有仪器是否足够可靠，能否在不扩展大架构的情况下取得 E2 级证据？

当前 H1→H2 递归续算具有较高准备度和理论价值，可以作为近期优先实验；但 Task B（记忆建网）、Task C（动态激活）和 Task E（蓝鲸竞争/重解释）必须保持独立科研主线，不能再次被“最新工程消费者”遮蔽。

# 9. 每份后续科研 TASK 的强制开头

以后任何科研 TASK 开始前，必须先写：

```text
科研命题：本轮在检验哪条理论主张？
理论位置：它属于哪一个核心问题族，与哪些理论相连？
当前证据：此前最高证据等级是什么？已有正结果、负结果和未决分别是什么？
替代解释：什么简单解释也可能造成同样结果？
干预设计：本轮只改变什么？什么必须保持不变？
目标证据等级：本轮最多能从 E? 提升到 E?；不能宣称什么？
工程需求：现有仪器是否足够；若不足，新增实现为何是实验所必需？
停止条件：何种首错使本实验失去解释力；哪些独立研究仍可继续？
```

然后才允许出现函数、接口、consumer、schema、测试数或实现文件。

# 10. 项目级成功与失败标准

## 10.1 中期成功

至少有多项核心假说达到 E2–E3：

- 结构表示有独立认知收益；
- 记忆形成多入口网络有独立收益；
- 当前处境能改变激活/工作集；
- 中间认识能递归参与后续推演；
- 多解释竞争和修订存在可控因果效应；
- schema / 人物认识能迁移到未见场景。

## 10.2 总假说获得强支持

至少出现 E4 级纵向证据：

> **相同引擎、相同基础模型、不同经历历史 → 在未见新情境中产生稳定而可解释的注意/理解/选择差异；差异可通过历史消融削弱，并在新反例下发生有依据的修订。**

此时才有资格讨论“经历驱动的人格形成”获得了实质支持。

## 10.3 需要质疑整体方向的情形

若在可靠实验条件下反复出现以下情况，应允许收缩甚至否定相关理论，而不是继续复杂化工程：

- Gold / 人工正确结构也不能提高目标认知能力；
- 多入口网络与简单强基线没有独立差异；
- 动态激活只能由人工标签或固定任务脚本产生；
- 中间认识无法稳定进入下一层推演，或只能靠预写结论；
- 不同人生无法在 held-out 场景产生可归因差异；
- 所谓人格差异主要由预训练角色知识、提示风格或表面标签解释。

# 11. 对当前工程工作的重新定位

SourceRef、Registry、CurrentState、MeaningCard、MemoryAccess、D控制、工作区、依赖账本、主体回程、E/F边界等，全部视为**科研仪器与可执行机制候选**。

今后工程工作的价值判断标准不再是“又接通了一段”，而是：

> **它是否让某条科研假说第一次变得可检验，或让现有实验排除了一个重要替代解释。**

没有服务科研问题的接口完善属于工程维护，不自动记作科研进展。

---

# 12. 最终研究原则

> **ECR 不是为了证明我们能搭一套复杂的认知中间件。**
>
> **它要回答的是：个人过去能否通过可执行的认知机制，真正长成现在的理解、联想、判断与选择；这些现在又能否继续改变未来。**
>
> 工程必须服务于这个问题，不能反过来缩窄这个问题。
