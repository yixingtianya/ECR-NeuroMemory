# ECR 总纲
## 持续关联、稀疏激活与知识塔专家化

**2026-10-09｜研究总纲，不代表实现完成。**

## 一、底层概念

**关联不因一次输出而终止；已有关系不断被激活、组合，新关系继续进入同一过程，持续叠加、展开与修订。**

核心不是“保存更多知识”，而是让后天形成的关联，获得像既有认知一样参与后续计算的地位。不能把可检索的知识库，等同于已经参与认知运算的关联网络。

人格不是预先安装的人设，而是这一持续过程逐渐积累的个体差异。

## 二、统一运行

```text
外界输入／内部认知分片
  → 激活相关关系链
  → 选择、展开与碰撞
  → 形成关联候选、当前认识
  → 再次激活、关联与处理 ↺
                  └→ 选定内容 → LLM 成句
```

说话只是输出的一种表现，语言片段也可回流。无外界提问时保留低频内省；提问提高相关处理频率，并提出回应要求，而不是从零启动认知。认知连续不等于逐秒存档，也不要求每个片段永久保存。

## 三、已有理论如何服务这一过程

何乐礼是完整的认知实现流程，**RAG＋Transformer 是技术底座**；以下理论解释其中的不同侧面，不是互相独立的系统。

| 理论 | 在同一过程中的作用 |
|---|---|
| 微元法／通用字段 | 提供极简、高逻辑密度、可寻址的关系单元；字段支持多对多关联，不是固定填空题。 |
| 拼图 | 内容自带局部关系；经关联连接成链。链式存储、链式返回，不拆成孤立节点再让 LLM 重建。 |
| 类神经元 | 输入决定关注点与入口，激活沿已有关系在不同记忆网络间传播。 |
| 侦探 | 活跃记忆与思维碰撞，在关联约束下形成桥梁候选；新认识继续参与碰撞。补缺是其局部表现。 |
| 蓝鲸 | 外来信息与派生内容怎样成为个人认识，以及认识的维持、共存、竞争与修订。 |
| 聚沙成塔 | 关系积累形成可复用的知识塔；塔提供入口，帮助后续知识展开、关联，逐渐产生专家效应。 |

## 四、AI 落点：知识塔优先，通用模型兜底

**RAG 参与稀疏激活，Transformer 处理当前活跃关系；无需每次加载全部记忆。** 激活方向随输入与内部结果迁移，而不是只在问答开始时检索一次。

知识塔是持续关联中长出的**领域专家**：不仅有资料，还拥有入口、内部关系与可复用逻辑链。塔之间可以交叉、协作，不必各配一个独立模型。

**通用 LLM 作为最低优先级的缺省知识来源。** 有适用的塔就优先展开；局部知识或关联不足时，向它取得补充候选，再进入何乐礼的同一认知流程。这样，知识库较小时仍有基础能力，后续积累又能形成自己的专家。

知识补充与语言表达是 LLM 的两种不同用途；关注、采用与最终表达内容仍由何乐礼决定，补充知识不自动成为个人经历。这里借用 MoE 的稀疏专家原则，不把知识塔直接等同于参数专家。

## 五、检验标准

**新关联能否在后续输入下被自然激活，带着关系继续展开、组合，并参与更多关联的形成？**

只保存成功、召回成功或回答更像人，都不足以证明这条主线成立。
