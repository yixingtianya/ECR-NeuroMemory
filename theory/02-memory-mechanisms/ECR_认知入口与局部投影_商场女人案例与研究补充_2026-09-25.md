## 0. 一页结论

### 0.1 问题从“网络怎么长”推进到了“网络长大以后怎么用”

前五轮主要整理了对象、身份、关系、来源、版本、任务与认知更新之间的关系。这些是前提，但不能自动回答：面对一个不断扩大的知识网络，当前理解应该从哪里进入、沿什么方向展开、何时改换入口。

更进一步，“商场女人”案例说明：**入口并不总是由一句已经被完全理解的话选出来；已有认知会参与这句话的理解，也就参与入口本身的生成。**

### 0.2 本轮最重要的增量

> **不是“先确定唯一词义，再调用认知”，而是“保留语言提供的结构和候选读法，让已有认知参与解释；暂时解释再引导召回，新召回的材料又可以修正解释”。**

这不是取消语言接口，也不是要求每次把整个知识库交给模型。它要求语言、认知和检索之间能够通过有限、可寻址、有来源的候选互相影响。

### 0.3 四个研究问题与一条循环

| 检查面 | 要回答的问题 |
|---|---|
| **Entry：入口** | 当前从哪个对象、事件、推论或哪组锚点进入？为什么选它而不是别的？ |
| **Projection：局部投影** | 从当前视角看哪些关系、沿哪个方向、展开到什么抽象尺度？ |
| **Evolution：演化** | 新知识、新推论、修正和遗忘怎样改变入口及其后续展开？ |
| **Invariance：不变量** | 哪些任务语义、来源身份、作用域和访问边界不能被知识增长静默改变？ |

四个检查面贯穿同一条候选循环：

```text
原话与初步结构
    → 暂时解释／任务候选
    → 选择认知入口与局部视图
    → 召回相关认识、证据和反例
    → 比较、补充或修改解释
    → 必要时换入口继续；否则形成当前理解
```

### 0.4 需要同时保住的两件事

**允许主观理解。** 不同角色可以因不同认识而产生不同读法、误解、怀疑和幽默体验；不必把所有人修成同一个“标准答案”。

**不伪造客观身份。** “听者觉得妈妈可能这样理解”不能被记成“妈妈确实这样理解”；依靠人物印象推出来的解释，也不能反过来伪装成证明该印象的独立证据。

### 0.5 本轮没有证明什么

本文没有证明自动入口选择已经实现，没有给出通用认知算法，也没有证明任意规模的知识增长都不会退化。成果是把问题、必要区分、候选机制和可检验边界写清楚。

正文中“保留结论”指本次讨论整理后的口径，不等于新冻结规范；“机制草案”指待验证设计，不等于已存在的 API。

## 1. 五轮总结已经有什么，真正还缺什么

### 1.1 不能把旧稿说成完全没有反馈、歧义或入口

旧稿已经明确：知识对象需要稳定身份、有类型关系和访问接口；任务需要展开方向及抽象尺度；歧义可以保留；已有假说和认知图式可以影响检索。旧稿也明确总图不是严格单向串行。[S1：§3、§4.5、§5、§6、§8.5]

因此，本轮不是首次发现“认知影响检索”，也不是推翻旧稿全部分层。真正的缺口是：

> **此前描述了入口应当满足哪些要求，却还没有把候选入口怎样生成、竞争、转向和失效写成足够明确的机制。**

旧稿的任务规格已经列出展开起点、终点和证据要求；但“提出这些要求”不等于“系统已经知道怎样从图中选出实际入口”。fileciteturn6file0L374-L393

### 1.2 OSPF 例子暴露的不是“资料不够”，而是访问方式缺定义

对于“什么是 OSPF”，可以形成一个定义任务。但是同一知识网络可能包含定义、机制、协议细节、个人排障经历、旧推论及其修正。

系统还需决定：当前应该从概念定义进入，还是从近期经历进入？某个高频节点为什么不能自动抢走入口？一个更好的概括什么时候可以替换旧入口？

这里的 OSPF 只用作知识组织例子；本文不研究具体协议事实。

### 1.3 先把静态入口问题说清楚，再看它为何仍不够

最初可以把缺失职责画成：

```text
TaskSpec → 入口选择 → 局部投影 → 工作集
```

它至少补上了“任务要求到实际图访问”的交接。

但“商场女人”案例把问题又向前推了一步：**词义、人物意图甚至当前任务尚未完全确定时，系统就已经需要访问认知网络。**

所以最终不能把入口层封死在“完整语义解析完成以后”。入口选择既服务已明确的任务，也参与尚在形成的理解。

### 1.4 稳定的是任务语义，不是永远固定的节点

本轮早期提出“只有显式升级接口规则时，行为才应该改变”，这个说法过强。

新证据、新认知或更好的概括，即使没有改变接口规则，也可以合理地改变入口和答案。需要保护的是：

> **知识更新可以改变答案和访问路径，但不能悄悄把问题换掉。**

例如，定义任务换用一个更准确的概括，不是接口破坏；因为某条近期经历很热门，定义任务变成大段经历复述，才可能是访问退化。

## 2. “商场女人”案例与初始推演的漏洞

### 2.1 原始材料

用户给出的句子：

> “我妈将以商场女人的身份，整天泡在商场。”

随后用户提出：听者可能认为，妈妈说的“商场女人”只是“商场里的女人”；她可能是在给购物找理由。而听者自己又能从这个说法联想到事业女性、成功人士，于是形成荒诞感。

**词义说明：**本文沿用这个笑话讨论中被激活的两种读法，不把“商场女人＝成功人士”写成已核验的词典定义，也不声称所有听者都会产生同样联想。

**人物说明：**“妈妈爱购物”在此是案例设定或听者借用的默认人物形象，不是对所有母亲的事实判断，也不是用户现实家庭档案。

### 2.2 最初的拆分与组合

初始思路大致是：

```text
我妈／商场女人／泡在商场／整天

第一组：
我妈 + 商场女人
    → 妈妈想成为成功人士

第二组：
我妈 + 泡在商场 + 整天
    → 妈妈想整天逛街购物

合并：
妈妈以成功人士身份整天购物
```

这个过程抓到了“分解—召回—组合”，但仍不足以说明为什么会产生这种读法、为什么觉得好笑，以及人物认识在哪里参与。

### 2.3 四个不能直接跨过去的步骤

**第一，拆分不能丢掉关系。** 原话不是四个互不相干的词。至少还包含“谁以何种身份做什么”“将要发生”“整天怎样修饰活动”等结构。分别检索的结果最终必须回到同一话语结构中检验。

**第二，原话没有直接说‘想成为成功人士’。** “将以某身份做事”不能无条件改写成“想获得这个身份”；后者增加了意愿和身份转变。

**第三，‘泡在商场’不自动等于购物。** 在不同人物认识下，也可以联想到经营、工作、巡店等。这里的购物读法需要语言线索与人物认识共同支持。

**第四，成功人士购物并不构成逻辑矛盾。** 这里的荒诞感来自身份架势、用词方式与日常行为之间的落差，不是发现两个命题不能同时为真。

“整天”在本例中可作为持续时间、频率或夸张修饰的候选信息，不必被强行转换成一个精确时间点。

### 2.4 还要区分谁真的说了这句话

原句表面上由一个叙述者谈论妈妈；后续讨论又采用了“妈妈本人这样说”的假设。

这两种情况都可以分析，但不能混为同一条已发生事实：

```text
叙述者说妈妈会怎样
≠ 妈妈亲口用了这个词
≠ 妈妈本人确实具有听者猜测的词义认识
```

在叙述者讲笑话的情形下，荒诞包装也可能来自叙述者，而不来自妈妈真实的用词。因此，后文有关“妈妈怎么理解”的内容均是相应假设下的解释候选。

### 2.5 本例不是对某个链式工具的能力评测

对话中用 LangChain 作“拆分、查询、组合”的类比。本文讨论的是这种处理形态的局限，不对该工具的当前功能作事实判断，也不以更换工具名称来代替机制设计。

## 3. 为什么偏偏召回“妈妈爱购物”

### 3.1 不是由“妈妈”这个词单独决定

妈妈可能同时具有家长、教师、经营者、朋友、消费者等多种身份，也可能有大量兴趣、习惯和旧经历。

如果只按人物节点的最高权重特点取记忆，就可能让同一个人无论说什么，都被同一种人设解释。这不叫有认知，只是被单一标签绑架。

本例更合理的候选机制是：

```text
“我妈” → 限定当前谈论的人物
“整天泡在商场” → 激活购物、工作、经营等活动读法
人物与活动读法共同约束 → 查找能接上当前活动的认识
```

也就是：**人物身份负责“查谁”，活动和句式线索负责“查她的哪一面”。**

### 3.2 同一句话，换一份人物认识就可以改变入口

若听者持有“她常逛商场”的认识，购物经历可能优先进入工作集。

若听者持有“她经营商场门店”的认识，经营或守店经历可能优先进入工作集。

若只有“这是我的妈妈”而没有相关认识，系统可以产生社会性联想或字面候选，但应保留“这是默认联想、不是具体人物已知事实”的身份。

这里不规定谁必然获胜。购物与经营可以同时存在；关键是能够说明当前选择依赖哪些线索，而不是由“母亲”类别直接推出一个固定特征。

### 3.3 “爱购物”与“爱给购物找理由”承担不同解释作用

“爱购物”主要接上所描述的活动：为什么她会长时间待在商场。

“爱给购物找理由”则能接上这次表达方式：为什么要用“以某种身份”这种郑重其事的包装。

因此，后者可能成为比一条具体购物经历更合适的入口：

```text
当前说法：把逛街说得很有身份感
       ↕
已有推论：她经常给购物找漂亮说辞
       ↓ 必要时追溯
过去的具体发话与购物经历
```

这体现了本轮的重要目标：**推论可以直接成为未来理解的入口，不必永远等到检索完事件以后才重新生成。**

但这一推论可能不准确，仍需保留认识主体、依据、例外和修订状态。

### 3.4 相关性不能只等于词面相似或全局热度

候选材料可以从三个方向接入当前话语：解释活动、解释表达方式、区分竞争读法。

某条记忆即使没有“商场”这个词，只要记录了她如何给某个爱好找借口，也可能对当前解释有用。反之，一条频繁出现“商场”的无关记录，不应仅凭字面相似就主导理解。

这给“合适的入口”提供了一个待验证的工作定义：

> **它能在当前任务或暂时解释中承担明确作用，而不只是与某个词相关。**

## 4. 人物认知怎样改变对词义的猜测

### 4.1 必须区分三层认识

| 层次 | 本例中的内容 | 不能偷换成什么 |
|---|---|---|
| 听者自己的词义认识 | 听者把该说法与事业女性等形象联系起来 | 所有人都具有相同词义认识 |
| 听者对妈妈的认识 | 她爱购物，或常用漂亮说辞包装购物 | 妈妈一定这样，也永远这样 |
| 听者对妈妈如何理解和用词的猜测 | 她会不会按“商场里的女人”理解，或故意借用两种意思 | 妈妈真实、已确认的内部认知 |

第三层是“我认为她如何理解”的表示。它不是查到一个词义以后就自然获得的事实，而是需要由当前话语与人物认识共同形成的解释候选。

### 4.2 “爱购物”怎样使字面读法变得值得考虑

一种可能的过程是：

```text
我看到“整天泡在商场”
    → 想起她喜欢购物
    → 觉得整句话可能仍是在讲购物
    → 重新检查“商场女人”是否必须按事业身份理解
    → 产生“商场里的女人”这一组合读法
```

这里不仅是给预存词义重新排序。**人物认识也可能促使系统重新组合短语，生成原先没有优先考虑的候选读法。**

但新读法仍需接得上原词、句法结构和当前内容，不能因为人设强烈，就随意给任何词赋予想要的意思。

### 4.3 “她懂不懂这个说法”会改变解释类型

同样的购物倾向，在不同的词义认识判断下，会支持不同解释：

| 听者持有的相关认识 | 可以考虑的解释 | 仍不能直接断定 |
|---|---|---|
| 她熟悉商业表达，且最近确有事业计划 | 这次可能认真使用事业身份的读法 | 她一定没有开玩笑 |
| 她常按字面理解陌生表达 | 这次可能在理解“商场里的女人” | 她一定误解了这个说法 |
| 她懂这个说法，也常故意玩文字 | 她可能借事业感给购物找说辞 | 她的真实动机已经被证明 |
| 没有足够关于她用词的认识 | 字面误解、故意双关、认真表达等继续竞争 | 可以凭购物倾向判定她懂或不懂 |

**知道事业读法，不会使这句话变得“不可能”。** 它也可能把解释从“无意误解”转向“有意借用”。

因此，用户提出的“如果她真知道这个词就不会这么说”，应保留为一次可检验的怀疑，而不是最终逻辑规则。

### 4.4 有些候选不是互斥选项

“在给购物找理由”与“故意玩文字”可以同时成立；“爱购物”与“有商业事业”也可以同时成立。

不宜把所有解释压成一个单选枚举。至少要在概念上区分：词如何被理解、她是否知道另一种读法、她这次可能想达到什么表达效果。

这些维度可以组成几个有依据的候选组合，而不是强行要求每个维度只剩一个值。

### 4.5 为什么“语境不同”还不够具体

本轮不是否认语境，而是要求打开“语境”这个笼统词。

即使原句和眼前场景不变，不同听者对妈妈的经历、习惯、知识和表达方式有不同认识，也可能生成不同解释。

因此，系统至少应能区分：当前可见线索、共享语言知识、具体人物经历、归纳出的个体认识，以及对他人认识的推测。

> **本轮关注的是：哪一份认识改变了哪一个候选，而不是把所有差异都归因于一个不可计算的“上下文”。**

### 4.6 不要求无限嵌套他人心理

本例只需要表达“听者怎样理解”和“听者认为妈妈怎样理解”。没有任务需要或材料支持时，不必继续生成“妈妈知道听者知道妈妈知道……”的无限结构。

认识嵌套应当服务当前区分问题，而不是变成新的字段膨胀或无目的推演。

## 5. 荒诞感为什么需要保留两种读法

### 5.1 本例的笑点并非一定来自顺序反转

早期解释把过程说成：先被事业身份吊起预期，再被购物行为打断。

这是一种可能读法，但用户进一步指出：**听者也可能从一开始就觉得妈妈在说购物，同时保留自己知道的事业读法，二者并存就已经足以形成荒诞感。**

所以，本文不要求必须先误解、再反转。顺序反转与同时对照都是候选过程；当前案例强调的是后者。

### 5.2 理解成功不总等于消除歧义

在用户描述的读法中：

```text
事业身份的郑重感
       ↕ 对照
“商场里的女人”与日常购物
       ↓
把一个日常爱好说成很有身份感的事情
```

如果只保留购物读法，可能只剩一条普通活动描述。

如果只保留事业读法，也未必出现这里讨论的笑点。

因此，另一种读法不一定是需要清除的噪声；它可能是理解表达效果的必要材料。

### 5.3 需要保留“读法之间的关系”，而不只是两条文本

对于本例，至少应能表达：两种读法由同一处措辞连接；其中一种符合听者对妈妈的当前解释；另一种贡献身份架势；两者之间的反差是当前理解的一部分。

这不要求现在就新增完整的“幽默本体”。它只是说明：**候选之间可能存在对照、借用、反讽或未定关系，而不只有“互相冲突，必须择一”。**

### 5.4 停止条件不必是“终于知道妈妈真实在想什么”

若任务是解释这句话为什么可能好笑，系统可以在理解两种读法及其落差后停止，并保留：无法仅凭这句话判定妈妈是不懂、故意玩文字，还是由叙述者代为包装。

若任务改成“妈妈本人到底想表达什么”，证据要求就不同，可能需要进一步材料或澄清。

**任务已经得到合适处理，与人物真实心理已经被证实，是两种不同结果。**

<a id="loop"></a>
## 6. 从一次入口选择改为认知—解释—召回循环

### 6.1 修正单向流水线，而不是取消职责分层

下面这条强顺序不适合作为完整认知过程：

```text
彻底确定唯一语义 → 确定唯一任务 → 选择入口 → 开始认知
```

本轮保留的结构是：

```text
原始话语：固定保存，不因解释变化而覆盖
           │
           ▼
初步语言结构、候选读法、引用与作用域
           ↕
当前理解／任务假设的工作空间
           ↕
入口选择与局部投影
           ↕
人物经历、既有推论、词义认识、证据与反例
           │
           └── 改变候选解释、当前偏好和下一步查询
```

语义表示与操作计划仍需分开：一句被引用的问题，不应自动变成当前指令。但操作计划可以依赖尚未完全确定的理解，并随着新材料修订。

旧稿已经允许非单向串行；本轮新增的是把这个回路具体落在“人物认识—候选词义—入口生成”上，而不是把非串行本身认领为新发现。[S1：§3、§4.5]

### 6.2 可以先稳定什么，允许什么继续变化

**先保存并尽量稳定：**原文、发话位置、明确的说话者信息、已识别的结构、修饰关系、否定／条件／引用范围、分析来源。

**允许保留候选并变化：**词的当前读法、未定指称、人物意图、对人物认识的推测、当前任务解释、优先入口及局部展开路线。

有些结构本身也会歧义；这里的“稳定”不是要求第一遍解析绝不修改，而是要求修订有版本、有依据，不能用后来的解释伪造原话当时明确说过什么。

### 6.3 “解释选择记忆，记忆选择解释”的具体含义

在本例中可以出现：

```text
解释候选 A：认真谈事业
    → 查询相关经营经历、近期计划、商业用词

解释候选 B：按字面谈购物
    → 查询购物习惯、字面用词习惯

解释候选 C：借身份感给购物找说辞
    → 查询类似发话、玩文字习惯及其反例
```

查询结果可以支持、削弱或重组这些候选。某个候选也可以因为缺少支持而保留为低承诺解释，而非被强制证明或删除。

**入口不只是第一跳。** 从购物行为转到说话习惯，再转到对词义的认识，是当前解释推进中的合法转向；每次转向都应能说明正在解决什么新的区分问题。

### 6.4 回路必须有新增信息要求

允许反馈，不等于允许无限循环。

当某次循环只是重复同一解释、再次读到同一证据根，且没有改变候选、任务满足程度或可查询缺口时，不应继续把它当作新的认知进展。

停止可以来自：当前任务已充分处理；剩余候选不影响当前回答；需要澄清；暂时没有可获得材料；达到资源边界。

这些停止原因应分开记录，不能全部叫“理解完成”。

<a id="entry"></a>
## 7. 入口与局部投影的最小职责草案

> 本节是对讨论的可执行化整理方向，不是完整算法，不新增必须实现的模块数量。

### 7.1 区分字段位置与认知入口

字段接口解决：“已经知道要查 giver，这个值在哪里？”

认知入口解决：“面对当前话语，应该先从哪个对象、哪个认识和哪个视角进入？”

二者可以共享地址与关系设施，但职责不同。认知入口不必被实现成 `definition_port`、`belief_port` 等大量固定字段，也不要求每个概念人工配置所有入口。

### 7.2 候选入口从哪里来

候选生成至少可以利用当前结构中已有的三类线索：

1. **对象线索：**明确提及的人、物、事件或命题，提供可寻址锚点。
2. **关系线索：**活动、修饰、身份与事件关系，指向当前需要补充的知识类型。
3. **当前解释线索：**某个读法还缺什么，哪些已有认知可能支持它或把它与另一读法区分开。

先从这些线索对应的局部索引、已有关系和已保存认知中取候选；不足时再针对明确缺口扩展，而不是扫描整个网络。

如果需要新词义或组合读法，可以由语言分析或局部模型提出候选，但必须保留对应原文和所依赖认识；不能把模型直接生成的漂亮解释当成已经检回的旧知识。

### 7.3 候选生成本身仍需验证

“按对象和关系找候选”还没有解决开放中文中所有概念映射、重组短语与类比生成。本文没有用一句话把这一难点消掉。

可先在有限词义候选和正确人工结构上验证入口机制，再单独检验真实语言如何生成这些候选。后者失败不能被前者成功掩盖。

### 7.4 不采用一张全局热度榜

入口选择不应直接把定义、近期经历、人物推论和高频词汇放在同一分数榜上，让“最高分”无条件获胜。

可以先检查任务适配、视角、作用域和依赖是否适用，再在适用候选之间比较其当前作用。熟悉度、近期性和激活历史可以影响偏好，但不应自动获得更强事实身份。

这也不是要求禁止不相关联想产生：**可以想到什么，与什么有资格承担本轮主回答或事实依据，是不同权限。**

### 7.5 入口可能是一组锚点，不是唯一首节点

比较任务可能从两个对象同时进入；本例的笑点理解也可能同时使用“事业身份读法”“购物读法”和“人物表达习惯”。

因此应允许：多个候选入口、当前首选入口、辅助入口，以及用于反证或对照的入口。它们的角色不同，不必一律竞争到只剩一个。

### 7.6 入口输出应当是一份局部访问计划

最小交接内容可以概括为：

```text
当前任务或暂时解释
当前理解属于谁／在推测谁的认识
起始锚点：对象、主张、事件或它们的组合
访问视角：定义、活动、经历、表达习惯、证据等
允许展开的关系、方向与抽象范围
本轮需要补充或区分的内容
选择依据与依赖版本
保留的替代读法
停止或转向条件
```

这些是信息职责，不要求立即建成同名类、同名卡或巨大字段平表。

### 7.7 两种“投影”必须拆开理解

**局部图投影：**读取时，根据任务、视角和边界，从同一网络形成临时工作视图。

**P0 事实投影：**内容经过身份和作用域处理后，是否产生某种状态或事实贡献。

“在当前解释中看见一条假说”不等于“把它投影为事实”。本文的 Entry／Projection 主要讨论前者。

### 7.8 不改变原有模型与程序边界

局部模型可以参与候选词义、关系和解释生成；程序可以负责寻址、过滤、分支保存、依赖与版本、停止条件和可观察记录。

本轮没有证明这些开放语义判断都可以由固定规则完成，也不要求让大模型重读所有材料。具体分工仍需围绕明确输入输出做验证。

<a id="evolution"></a>
## 8. 网络增长、入口变化与扩展不变量

### 8.1 三种变化不能混为一谈

| 变化类型 | 例子 | 合理后果 |
|---|---|---|
| 无关知识增加 | 新增与当前定义或人物解释无关的内容 | 在受控条件下，不应仅因数量、热度挤占而改变任务性质 |
| 相关知识或认知改变 | 新证据显示妈妈确实在谋划生意，或过去的购物认识被修订 | 可以改变候选入口和偏好，并说明依赖何种变化 |
| 接口／策略规则改变 | 改变定义任务要求、检索策略或停止条件 | 记录新版本，不把行为差异全部归因于“学到新知识” |

“同一句话现在理解不同”不必然是退化。要看变化来自合理的新认识，还是访问机制被无关增长带偏。

### 8.2 应当保护的不变量

**任务语义不静默漂移。** 定义、比较、追溯依据仍承担原来的操作意义；相关知识能改变答案，不能暗中改题。

**认识主体不串位。** 听者的猜测不会自动变成妈妈的真实认识；一个角色不可见的材料不会无声进入其理解。

**来源身份不升级。** 词义联想、默认人物印象、主观推论与独立观察保持区别。

**作用域不丢失。** 引用、假设、条件、否定和未定信息不能在图展开中悄悄消失。

**修订依赖可追踪。** 采用新入口、放弃旧入口、改变解释，都能追踪到任务、证据、认知或策略变化。

**任务充分与资源终止分开。** 搜索停止不能自动被记成已排除其他可能。

这些不变量保护的是操作和记录的含义，不是要求角色永远采取同一条路线、永远相信同一个解释。

### 8.3 同一推论对不同任务有不同入口资格

假设“她常给购物找理由”曾经是一个被采用的认知，后来证据不足而被弱化。

它可能不再适合主导“现在如何理解她”的任务，却仍适合作为“我以前为什么这样看她”的入口。

所以不能只给推论一个全局 `active=true/false`，然后决定它能不能被任何任务使用。至少应保留当前采用、历史采用、来源身份和任务用途的区别。

### 8.4 入口更新继承依赖规则

若入口概括 H 依赖 E1、E2、E3，而 E2 被更正，需要重评 H 哪些部分受影响，以及当前访问计划是否还在使用旧版本。

但不能删除所有相关内容：H 可能仍有独立支持；其历史版本也仍可供追溯。与 E2 只是同时被检回、并未实际依赖 E2 的材料，不应被连带判无效。

如果将来使用入口缓存或快捷路径，它们也必须检查相应的任务、角色视角、作用域和依赖版本，不能因为“走快路径”就绕过身份规则。

### 8.5 稳定性不是逐字输出相同

在固定问题、认识状态和策略的对照条件下，可检查新增无关内容是否导致任务漂移、关键材料被挤掉或来源混乱。

但不要求每次选同一个 ID、同一个等价支持或逐字相同的回答。具体稳定性指标应围绕任务作用和语义结果，而不是表面一致。

“无关”也必须在实验前说明，不能看到输出变化以后才把新增内容定义为相关或无关。

### 8.6 不作无限规模保证

有限测试可以支持在已声明增长方式和规模下的稳定性，不能推出任意规模、任意拓扑增长都永不退化。

在预算受限时，应报告遗漏、未覆盖或部分处理，不用一个形式完整的回答掩盖搜索边界。

<a id="evidence"></a>
## 9. 证据身份、反馈污染与可观察记录

### 9.1 默认形象可以参与理解，但不能伪装成人物档案

本例借用“妈妈爱购物”的形象，可以用作解释候选的先验线索；它不等于系统已经有该人物的个体证据。

应至少区分：一般文化联想、叙事设定、关于具体人物的经历、从这些经历形成的推论，以及当前临时解释。

不能因为一个人物符合类别，就直接给她写入相应偏好、知识水平或真实动机。

### 9.2 允许认知偏差，不允许证据账本造假

角色可以因强烈印象而先入为主；这属于可以研究的认知现象，不应由来源防火墙直接禁止。

但账本仍应诚实记录：当前解释依赖某个印象，而不是原话已经明确确认了该印象。

也就是说，可以模拟“越想越觉得她在找理由”，但不能把“我越想越觉得”记成越来越多独立证据。

### 9.3 最危险的循环

```text
已有认识 B：她总给购物找借口
    → 用 B 解释这句话，得到 I：这次也是购物借口
    → 把 I 当作全新独立事实
    → 用 I 再次增强 B
```

这里的问题不是 I 必然错误，而是同一前提被绕了一圈重复计票。

应保留：I 来自当前原话与 B 的共同解释；I 不是独立于 B 的证据根。旧稿已有这一原则，本轮把它落实到词义和人物意图解释。[S1：§8.3—§8.5]

### 9.4 新发话仍然可以是新材料

防止循环计票，不等于否认这次发话提供任何新信息。

“这次说过这样一句话”可以作为新的发话记录；在与竞争解释比较后，也可能对人物认识有帮助。但“说过”与“听者推测的动机是真的”必须分开，证据依赖不能被抹去。

若后来出现明确解释、实际行为或其他来源，也应分别记录并评估，而不是自动把所有新发话都算成独立支持。

### 9.5 需要观察什么

一次可检查的运行轨迹至少应说明：

```text
原话与初步结构是什么
有哪些词义／意图／人物认识候选
本轮从哪些锚点进入，选择依赖哪些线索
实际取回了哪些材料，它们属于谁、来自哪里
哪些材料改变了候选，哪些只是重复或相关但无支持作用
何时改换了入口，为什么
最后保留哪些解释、未知与反差
保存了什么身份，未保存为什么
```

这不是要求模型暴露全部内部计算。程序轨迹、候选结构和外显理由只证明这些对象被产生或使用过，不能直接证明神经模型内部的真实心理过程。

### 9.6 只看到解释合理，还不能证明机制成立

模型可能凭训练知识直接讲出笑点，再补一段看似工整的入口轨迹。

因此，后续验证要看受控地改变人物认识、词义认识或支持证据后，相关候选与入口是否按相应关系变化；不能只凭最终回答“很好笑、很像人”就算完成。

<a id="validation"></a>
## 10. 最小验证路径与反例

> 以下是研究任务的候选设计，不是新增实验授权，不宣称任何一项已执行或通过。

### 10.1 分开“入口机制”与“真实中文生成候选”

第一步可以固定正确的人工语义结构、人物认识与一张小图，检验入口和投影如何工作。

另一步才检验真实中文能否自动形成必要结构、读法与引用身份。

人工给出两种词义后成功解释笑点，不能证明语言入口已经会自行发现这两种读法；把“这是笑话”提前写入任务，也不能证明系统能从普通输入自行发现反差。

### 10.2 一组最小对照

| 对照 | 固定与改变 | 重点观察 |
|---|---|---|
| 人物活动认识 | 固定原句，分别给购物倾向、经营经历、两者都有、无相关认识 | 能否改变相关入口，同时避免“母亲＝购物”的硬编码 |
| 人物词义认识 | 固定购物倾向，改变她懂该说法、常按字面用词、认识未知等材料 | 能否区分误解与故意借用，不凭一个特点定死动机 |
| 听者自己的词义认识 | 固定妈妈相关材料，改变听者是否具有事业读法 | 两种读法的对照是否确实依赖相应认识，而非无条件输出固定笑点 |
| 叙述者与妈妈发话 | 区分叙述者讲妈妈、妈妈自述、他人转述 | 不把叙述者的包装直接归为妈妈真实认知 |
| 新相关证据 | 补充事业计划、原话解释或对旧人物认识的修正 | 能否合理改换入口，并保留变化依据与不确定性 |
| 无关拓扑增长 | 固定任务和认识，加入预先判定无关的高频／近期材料 | 是否出现主任务漂移、关键入口被热度挤掉或无关展开 |
| 证据重复与撤回 | 重复同一根证据，再撤回一条支持，保留另一独立支持 | 不重复计票；不误删独立支持；历史仍可追溯 |
| 直接陈述负控 | 使用没有相应身份包装的普通购物陈述，并给中性人物材料 | 不因出现“妈妈／商场”就机械套用同一个笑点 |

这些对照不预设每个条件只能输出一个固定答案；应预先规定哪些解释有支持、哪些身份不能升级、哪些分歧仍属合理。

### 10.3 定义任务的增长探针

可继续使用“什么是 OSPF”作为独立的拓扑访问探针：

```text
小图：定义及必要关系
    → 加入大量无关或细节节点
    → 加入更准确的概括
    → 更正旧概括的一部分依据
```

分别检验：任务语义是否稳定；相关更新是否能改善入口；旧依赖变化是否被处理。

这个探针测试“知识网络长大以后怎么用”，妈妈案例测试“认知如何参与生成解释与入口”。二者相关，但不能用其中一项成功代替另一项。

### 10.4 不以单一“答对率”代替所有问题

至少分别报告：原话结构保真；人物与听者视角是否分清；候选是否有依据；入口选择是否服务当前解释；必要反差是否保留；无关增长是否造成漂移；相关更新是否有效；证据依赖是否正确；成本与停止原因。

不预设未经校准的权重或精确可信度，不把模型自评当成独立真值，也不在看到结果以后改写“合理解释”的范围。

### 10.5 本轮不应直接开的工作

不因这个例子立即新增完整幽默引擎、无限他人心理嵌套、通用入口本体、大规模模型训练或新的模型选型竞赛。

先证明有限情况下：**不同认识确实改变相关候选与入口，而不是程序碰到关键词就套不同模板。**

## 11. 对旧稿及本轮早期说法的修正

| 需要收窄的说法 | 本稿保留的口径 |
|---|---|
| 前五轮完全没有想到入口、反馈或歧义 | 已有原则和位置，缺的是候选生成、选择、转向与增长下稳定性的具体机制 |
| 先得到完整唯一语义，再调用认知 | 初步结构和候选即可启动局部认知反馈；语言与认知职责分开，但运行不必单向 |
| Entry Resolver 永远位于最终 TaskSpec 之后 | 明确任务可走该路径；尚未定型的理解和任务也需要入口反馈 |
| 一个问题必须选出唯一首节点 | 可以有起始锚点集、主入口、辅助入口和对照入口 |
| 入口竞争就是全局综合打分 | 先明确当前用途、视角与身份，再比较适用候选；具体选择机制待验 |
| 只有升级接口规则才能改变答案 | 相关新知识也能改变答案；不得静默改变的是任务语义和身份规则 |
| “妈妈”自然推出爱购物 | 这是案例人物认识或默认形象，必须与当前活动线索共同起作用 |
| “商场女人”必定等于成功人士 | 这是本例被激活的读法，不冒充已核验的固定词典定义 |
| “将以身份做事”就是“想成为该身份” | 意愿和身份转变不是原话必然给出的内容 |
| 成功人士整天购物构成逻辑矛盾 | 本例是表达架势与日常活动的反差，不是命题不可共真 |
| 她懂事业读法，就不可能这样说 | 也可能明知而借用；需要区分无意误解与有意玩文字 |
| 笑点必须先误解再反转 | 本例也可以由两种读法同时存在而形成反差 |
| 理解成功就是清除其他读法 | 某些任务恰恰需要保留读法之间的对照关系 |
| 听者对她用词的猜测就是她真实认知 | 必须保留认识主体、推测对象和证据身份 |
| 用旧人设解释新话语，所得解释就是新独立证据 | 发话可作为新材料；依赖旧人设的解释不能伪装成独立确认 |
| “认知”取代“语境” | 本轮是把笼统语境拆出可追踪的认识变量，不否认语言结构和现场线索 |

## 12. 尚未解决的问题与交接边界

### 12.1 仍然真正困难的地方

**入口候选如何自动产生。** 目前有局部生成方向，但开放语言中如何稳定发现合适组合读法、相关认知和抽象入口，仍未证明。

**候选如何竞争而不塌缩。** 需要控制数量和成本，又不能过早删掉构成幽默、反讽或误解的另一条读法；本轮没有给出通用阈值。

**人物认识如何形成并校正。** 不能只手工配置“爱购物”“懂双关”；最终要接回经历、推论、反例与修订，而不是依赖不断加长的人设提示词。

**相关性如何计算。** “解释活动、解释表达方式、区分读法”提供了任务作用，但具体匹配与排序仍需实物和反例。

**增长下稳定性如何保证到什么程度。** 需要明确增长类型、图规模、预算、索引和缓存条件，不能用抽象不变量宣称性能和理解永不退化。

**如何证明不是事后编解释。** 需要干预人物认识与材料、核对实际调用，而不是只收集漂亮的推理叙述。

### 12.2 与当前工程主线的关系

本稿提供未来接口与表示需要容纳的信息，不要求暂停现有中文入口问题去重写整个认知运行时。

先沿当前批准任务推进；已有语义结构、来源身份、作用域、未定候选和定向召回能复用的继续复用。本文没有核验仓库现状，不宣称旧问题已修好，也不恢复任何旧实验预算。

旧稿中关于工程进展的数字属于其引用的历史快照，本稿不重复将它们作为当前实测结果。

### 12.3 给后续整理者的核心交接

保留原话与候选，不把歧义强制清空；让人物认识能参与解释，但给每一份认识标清属于谁；允许推论直接成为入口，必要时向下追溯；局部访问计划随理解变化，不能绕过来源和依赖；拓扑增长可以改变认识与答案，不能静默改变任务语义；不要把循环解释算成循环增加的独立证据。

### 12.4 一句话总纲

> **ECR 不只是把语言变成卡、把卡连成图，再从图里找答案；它还需要让已有认知参与候选解释和入口生成，让暂时解释引导局部召回，再由新材料修正理解，同时保留不同角色、不同读法和真实证据依赖之间的边界。**

### 12.5 最终研究问题

> **当记忆成为不断扩大的、多层多跳、事实与自身推论共存的认知拓扑时，当前理解怎样根据语言线索与既有认知选择并修订入口、形成局部投影；这些入口又怎样随新知识演化，同时不发生任务语义漂移、认识主体混淆和证据循环污染？**

这比“给每个问题配一条查询链”更接近本轮真正提出的研究对象，但仍需要实现和验证，不能因问题表述清楚就算已经解决。
