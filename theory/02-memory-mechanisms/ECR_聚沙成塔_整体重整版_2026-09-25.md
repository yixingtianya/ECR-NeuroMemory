<a id="summary"></a>
## 0. 总结：塔不是“存得有条理”，而是“长大以后仍然会用”

### 0.1 最初目标没有变

ECR 的目标仍是：让经历不只是被保存和复述，而是参与后续理解、判断、表达和行为；让不同角色因各自经历与认识产生差异，并能在新证据到来后改变这些认识。[M1：§1、§8、§15]

因此，完整体系至少同时解释两件事：**认知网络怎样形成，以及当前认知怎样使用并改变这张网络。**

前五轮对第一件事及其治理边界整理得较多：对象、关系、来源、身份、版本、冲突、检索工作集与写回。用户后来的意见把第二件事准确地提出了：从哪里进入，为什么选这里，怎样展开，长大以后会不会越学越不会用。

### 0.2 重整后的中心问题

> **当记忆成为不断生长的、多层多跳、事实与自身推论共存的认知拓扑时，当前理解怎样依据语言线索、任务和既有认知选择并修订入口，形成局部投影；这些入口怎样随学习演化，同时不发生任务漂移、人物视角混淆和证据循环污染？**

这里的“拓扑”指对象与有类型关系组成的可访问网络，不额外声称某种数学拓扑理论或人脑实现已经成立。

### 0.3 最重要的架构修正

不能把整体机制固定为：

```text
先完全听懂一句话 → 再确定任务 → 再取记忆 → 才开始认知
```

更合适的总关系是：

```text
原话与初步结构
        ↕
暂时解释、当前任务、认识主体
        ↕
动态入口与局部访问计划
        ↕
已有知识、经历、人物认识与推论
        ↓
形成当前理解／保留分歧／提出澄清
        ↓
按身份记录变化；按当前任务表达或行动
```

**认知不是最后才对一句已理解的话发表评论；它从“这句话可能是什么意思”时就已经参与。**

但这不取消语言与认知的分工：原话支持什么、听者补出了什么，仍必须能分开查。

### 0.4 四个研究面

| 研究面 | 核心问题 |
|---|---|
| Entry：入口 | 哪个对象、推论或锚点组合先被采用？为什么是它？ |
| Projection：局部投影 | 从这个入口看哪些关系、向上概括还是向下追溯、走到哪里？ |
| Evolution：演化 | 新知识、新推论和修正如何改变已有入口及访问习惯？ |
| Invariance：不变量 | 什么变化是学习，什么变化是接口污染；哪些边界不能静默改变？ |

它们是检查同一机制的四个方面，不是要求新建四个系统。

### 0.5 结论身份

本文区分：**继承的原则、此次修正的解释、候选机制、尚未验证的能力。**后文的数据形状、访问规则和算法步骤均是设计草案，除明确引用历史报告外，不代表仓库中已经存在同名实现。

<a id="revision"></a>
## 1. 原有成果与实质修正：不是推翻，但必须重排重心

### 1.1 不能把原方案贬成“只是记忆库”

旧总稿已经纠正过一种夸张说法：原 v2.2 并非让模型包办一切，它已经包括结构化经历、跨经历抽象、推理充分工作集、来源与认识身份、版本和分阶段验证。旧总稿也允许歧义和非单向运行。[M1：§1、§3、§4.5]

所以，本稿不把“有反馈”“有来源”“有主观认知”重新包装成首次发现。

真正的增量是：**把此前被原则性允许的反馈，落实到词义形成、人物认识、入口选择和网络增长的关系上。**

### 1.2 五轮成果如何归位

| 五轮中形成的内容 | 本稿如何保留 | 必须修正的部分 |
|---|---|---|
| 分层与职责 | 保存语言、存储、检索、推演、写回、表达的分工 | 职责图不能被当作不可逆的时间顺序 |
| 统一语义表示与稳定身份 | 小结构可组合；Episode 可作为经历聚合；对象引用保持一致 | 统一存储不等于所有角色拥有同一种理解 |
| 任务、接口、缺口寻址 | 保留明确任务的定向查询与必要材料检查 | TaskSpec 可能尚在形成，入口不能只服务已完成理解 |
| 阶段观测与修订纪律 | 失败要定位，来源要留痕，未执行不能算通过 | 日志、格式和流程闭合不能自证语义正确 |
| 任务触发与新证据触发 | 两类触发都进入有限工作空间 | “补空”不是所有认知的统一算法，也不要求两套独立后台引擎 |

### 1.3 后续观点实际改变了哪些原章节

旧稿对“从一句话展开完整阐述”的解释需要重写：任务规格只是需求，不能代替入口选择。语言接口需要从“确定意义”改为“保存结构、容纳候选、接受有来源的认知反馈”。检索需要从“为已确定问题取材料”扩展到“为竞争解释取材料，并可能改变问题的当前理解”。

写回也要随之变化：不仅记录最终结论，还要区分解释依赖的人物认识、对他人认识的推测，以及这些认识对未来入口的影响。验证则必须加入认知条件干预、入口转向和知识增长探针。

因此，本稿的中心不是把两份旧文相加，而是用上述关系重新组织整个系统。

### 1.4 三种“接口”不要再混用

**结构地址**解决“giver 在哪里”；**任务语义**解决“DEFINE 要完成什么”；**认知访问**解决“此刻从谁的哪份认识、哪组节点进入，以及怎样看”。

三者相接但不能互相替代。字段地址存在，不等于系统知道该查这个字段；任务名字存在，不等于系统知道该选哪个入口。

## 2. 总架构：以当前理解的工作空间为中心

### 2.1 职责图

```text
                    原始话语／可见观察
                            │
                   原始记录与分析证据
                            │
                            ▼
                  语言结构与候选读法
                            ↕
        ┌─────────────────────────────────────┐
        │            当前工作空间             │
        │                                     │
        │ 暂时解释 ↔ 任务理解 ↔ 动态入口计划  │
        │    ↕                      ↕         │
        │ 关系推演、比较          局部图访问   │
        │    ↕                      ↕         │
        │ 当前判断、反差、未知 ← 取回的材料   │
        └───────────┬────────────────┬────────┘
                    │                │
              回答／行动计划     认知更新候选
                    │                │
                自然表达       来源、版本、采用管理
                                     │
                                     ▼
                         长期内容与认知存储
                                     ↕
                          为后续局部访问提供材料
```

系统定义、任务语义、执行策略和资源边界约束这整个过程。原始记录、角色可见性、作用域、依赖和观察轨迹贯穿各部分。

图中表达与长期采用是两个去向。**一个想法可以先作为假说表达或暂存，不必先升级成长期信念，更不必先成为事实。**

### 2.2 五类职责继续保留，但中心已经改变

| 职责 | 负责什么 | 本次重整的关键变化 |
|---|---|---|
| 语言入口 | 保留原话，形成有来源的结构与读法候选 | 不要求先完成唯一语义才能调用认知 |
| 内容与认知底座 | 保存对象、经历、主张、推论及各主体的采用状态 | 推论和人物认识本身可以被寻址为入口 |
| 认知运行 | 管理解释、任务、入口、局部投影与推演 | 从单次检索计划变成有界的双向迭代 |
| 记录与采用管理 | 保存、采用、修订、撤回，维护来源和依赖 | 入口偏好和访问缓存也要受依赖变化影响 |
| 回答与行动组织 | 根据当前任务选择表达内容、深度和行动 | 保留必要的多种读法，不把表达顺畅当作消歧成功 |

这些是职责，不要求创建五个新的包、模型或服务。

### 2.3 内容、认识、控制三个平面仍然有效

内容平面描述“某个命题、事件或关系是什么”；认识平面描述“谁这样认为、根据什么、是否正在采用”；控制平面描述“这次想完成什么、准备怎样访问和行动”。

认知可以改变读法和控制计划，但不能静默改写原话证据；控制策略可以选择阅读假说，但不能因此把假说变成事实。

**跨层允许反馈，跨身份不允许偷换。**

## 3. 知识底座：让网络既能组成，也能被再次进入

### 3.1 统一身份，不统一所有观点

需要分别标识：一次文本提及、实体、事件、命题内容、某次主张、经历聚合、认知图式与某个主体对它的采用记录。

同一个人可以有多个称呼；相同参与者可以反复发生同类事件；同一命题可以被不同人相信、否认或转述。一次事件的多次转述不能因此变成多次独立经历。

“一个权威存放位置”只能表示记录身份和版本一致，不表示系统只有一个正确观点，也不表示存储中的所有内容对所有角色可见。[M1：§3.3、§5.2、§8]

### 3.2 三类逻辑内容，不强制三套数据库

| 类别 | 内容 | 访问边界 |
|---|---|---|
| 运行规则 | 表示定义、任务语义、执行策略、字段目录与版本 | 不能当作角色亲历或普通世界证据 |
| 话语与世界材料 | 原话、观察、事件、规则性知识、主张和来源 | 必须保留“谁说的／如何得知／在哪个范围成立” |
| 主观认知 | 假说、人物认识、信念、自我模型、跨经历图式 | 带主体、支持、反例、采用状态和历史 |

它们可以共享存储设施和对象引用，但不能在检索或写回中抹去类型差异。

### 3.3 关系必须有类型，也必须有认识身份

世界关系包括参与者、先后、条件等；证据关系包括支持、反驳、转述和推导依赖；抽象关系包括实例、概括和适用范围；任务关系包括本轮的比较维度、展开目的和临时顺序。

“相关”不是“导致”，“由某人说出”不是“由某人造成”，“沿一条边反向查找”也不是把这条边的语义方向反转。

因果边或模式边可以作为假说长期保留，但必须带假说身份。不能因为它被画进长期图，就把它当作确认事实。

### 3.4 Episode 保留，通用结构更底层仍是候选设计

```text
谓词、角色、状态、操作符、引用与变量
                ↓ 组合
      事件／问题／主张／规则／经历
                ↓ 跨经历整合
       认知图式／人物认识／自我模型
                ↓ 再次参与
          后续解释和入口选择
```

Episode 适合记录有时间、场景和来源边界的具体经历，不必强迫问题、定义和规则先“伪装成经历”。但通用结构如何兼容既有 Episode 与 P0，仍需具体裁决；本稿不宣告迁移已完成。[M1：§4.2]

### 3.5 横向关系、纵向抽象和访问视角

横向关系决定可以联系什么；抽象方向决定现在谈整体、机制、过程还是细节；访问视角决定当前是在问定义、追溯依据、回忆经历，还是理解某个人的看法。

同一认知可以向下追溯经历，也可以向上参与更一般的模式，还可以横向与反例比较。不存在所有任务都适用的一条固定知识树。

讲解顺序主要属于当前任务计划。教学偏好可以长期保存为策略，但不能伪装成世界因果关系。

### 3.6 六个状态不要压成一个 active

应分别回答：这条内容是什么认识身份；角色能否接触；是否已进入相关索引；本次能否检回；有没有进入工作空间；对本轮承担了什么作用。

后者可以是主解释、例子、反例、对照或历史材料。**被保留不等于被相信，被激活不等于被采用。**

<a id="language"></a>
## 4. 语言接口重定义：保留结构，不预先封死理解

### 4.1 不把“完整理解”设为认知启动条件

“完整字段底座＋稀疏实例”继续保留：完整的是声明范围内、带版本的结构定义；实例只保存已有依据的内容。定义某个字段，不代表解析器会抽取，也不代表本句话已经给出答案。

词义、指称、语气和结构本身都可能有候选。第一遍分析可以提供启动线索，不必等到全部消歧才能查认知网络。反过来，查网络也不要求每次重读全部记忆。

**语言分析与认知解释有职责区别，但不存在一条必须完全不受认知影响的“纯理解完成线”。**

### 4.2 原话、分析与解释分账

至少需要保留三类记录：

| 记录 | 例子 | 如何修订 |
|---|---|---|
| 原始材料 | 原话、来源、实际说话者、文本位置 | 保留历史，不被后来的解释覆盖 |
| 分析候选 | “以……身份”结构、活动修饰、指称候选、否定范围 | 允许重分析，保留版本及依据；不自称必然正确 |
| 主体解释 | 听者认为她在购物、误解短语或故意玩文字 | 带认识主体、依赖和替代解释；不是原文明示事实 |

分析器产生的标签也是一个输出，不是天然的语义真值。原始跨度可以固定，分析及绑定可以版本化修改。

旧稿要求 explicit、normalized、inferred、unknown 分开，本稿继续保留这一纪律。引入认知反馈后，更不能把由人物认识补出的动机塞回“原文明示”字段。[M1：§4、§9、§10]

### 4.3 语义与执行分离仍然成立

```text
“小林问过：谁把资料袋给了阿望？”

语义：记录小林问过一个以 giver 为焦点的问题。
执行：当前是否需要回答这个问题，取决于本轮任务和引用身份。
```

内部出现问题或命令，不自动获得当前执行权限。现在修正的只是时间顺序：语义候选和操作计划都可以在后续材料影响下修订，不必先得到一个永不变化的完整意义。

TaskSpec 应区分已明确的用户任务与系统暂时猜测的任务。后者改变时需要说明依据，不能因为检索到了另一类材料，就悄悄把用户的问题换掉。

### 4.4 认知反馈可以做什么，不能做什么

它可以使某种读法更值得考虑，可以促使短语重新组合，可以选择相关指称，也可以提出“她是否故意这样说”的候选。

但新读法仍需指出对应措辞、结构或可见线索。人物印象再强，也不能使任意句子都被解释成同一件事。

若出现“她今天明确说不去购物”，购物印象可以使听者怀疑她会改口，却不能把那句否定抹掉，记成“她说要去购物”。怀疑是另一条主观记录。

### 4.5 歧义有不同用途

有些歧义妨碍行动，需要澄清；有些不影响当前任务，可以暂存；有些正是幽默、反讽、借用或误解的组成部分，需要保留读法之间的关系。

因此，不能以“候选越少越好”作为通用理解指标，也不能以“始终保留所有候选”代替有效选择。需要依据当前任务决定哪些差异必须区分、哪些读法必须对照、哪些暂时无需展开。

<a id="perspective"></a>
## 5. 认知不是一个总标签：谁知道什么，谁认为谁知道什么

### 5.1 把“语境”中的认识变量打开

本稿不是宣称“语境”一词错误，而是避免用它掩盖机制。同一句话、同一现场，听者对一个人的经历、习惯、知识和表达方式不同，也可能产生不同解释。

所以运行时需要使用可追踪的认识，而不只是一个含糊的 context 字符串：当前可见材料、听者的词义知识、具体人物经历、归纳出的认识，以及对他人理解方式的猜测。

### 5.2 三层认识不能合并

```text
第一层：我怎样理解这个说法。
第二层：我认为妈妈平时是什么样的人。
第三层：我认为妈妈这次怎样理解、怎样使用这个说法。
```

第三层可以依赖前两层，但不因此成为妈妈真实的内部认知。

一种说明性表示是：

```yaml
# 结构职责示例，不是冻结字段或现成 API
认识主体: 听者L
对象: 妈妈M
内容: M可能把这处短语理解为“商场里的女人”
身份: 对他人理解方式的假说
对应话语: U1中的“商场女人”
依赖:
  - L关于M购物倾向的认识
  - U1的活动和身份措辞
未确认:
  - M是否知道另一种读法
  - M是否故意玩文字
```

在存储中，这条记录属于 L 对 M 的猜测。不能把它直接写进“M 确实知道／不知道什么”的事实视图。

### 5.3 人物认识不是一整块固定人设

同一个人可以既爱购物又经营门店。哪一面参与此次理解，需要由当前对象、活动、说法和任务共同决定。

“妈妈”提供人物锚点；“整天泡在商场”提供活动线索；“以某种身份”又提供表达方式线索。这些线索可能分别接上购物、经营、夸张、找理由等不同认识。

不要求所有读者都经历相同的先后步骤。一个常被激活的人物印象可以很早参与；它仍须与当前语言材料共同检验，而不是独占所有解释。

### 5.4 默认形象与具体人物档案分开

“妈妈爱购物”在本案例中可以是笑话借用的默认形象，也可以是听者对这个人的已有认识。二者都可能影响解释，但来源不同。

默认形象不自动成为个体事实，个体经历也不自动成为关于所有母亲的规律。本文不把案例写成用户现实家庭信息，更不将人物类别固化为系统硬规则。

### 5.5 对他人的认识只展开到任务需要的深度

本例需要“听者的读法”与“听者推测妈妈的读法”。没有材料或任务需要，不继续生成无限嵌套的心理模型。

人物的词义认识、行为倾向和表达意图也是不同维度。“她爱购物”不足以证明她不懂某个词；“她懂这个词”也不足以证明她不会借用它开玩笑。

## 6. 动态入口：从任务要求到可访问对象的交接机制

> 本节给出候选机制，不用“选合适入口”一句话代替具体职责；但也不宣称开放语言的候选生成与排序已经解决。

### 6.1 入口不是单个节点编号

一个认知入口至少包含：**锚点、访问视角、当前用途和展开约束。**

同一条“她常给购物找理由”的推论，可以作为解释当前话语的先验，也可以作为被质疑的对象，或作为追溯旧看法的起点。节点相同，用法不同。

比较和笑点理解还可能需要一组锚点，不应预设所有任务都必须选出唯一首节点。

### 6.2 尚未完全理解时，怎样启动第一次访问

启动不依赖完整 TaskSpec。可以先使用原话中已经识别的局部线索：人物提及、谓词或活动、短语边界、修饰关系、疑问焦点，以及当前会话中已明确的任务部分。

候选入口可以沿三条来源生成：

| 来源 | 如何取得候选 | 边界 |
|---|---|---|
| 由话语向知识 | 用实体候选、活动框架、词义候选访问局部索引与类型关系 | 不是只按单词相似；未定指称保留分支 |
| 由已有认知向话语 | 检查当前相关的图式、人物认识、历史未解决问题能否解释这处结构 | 不是把全部人设或记忆塞进输入 |
| 由竞争解释提出新查询 | 找能补关键关系、区分读法或提供反例的材料 | 查询内容及结果都保留对应的假说身份 |

例如，“人物M＋长时间待在地点”的结构可以召回 M 在该地点的不同活动认识；“以某身份做日常行为”的结构则可能召回关于表达习惯的认识。

新组合读法可以由现有语言机制或局部模型提出。它要标为本轮生成，不能伪装成原来就存着的知识。生成能力仍需单独测试。若暂时连可用的对象或活动锚点都无法形成，应保留原话、继续局部分析或在必要时澄清，不能假装已经选出了入口。

### 6.3 候选至少要能说明自己来干什么

候选不只携带一个相关性分数，还应能指出：

```text
从哪处原话／哪个当前问题触发；
准备从什么对象或认识进入；
要补充、解释、比较或区分什么；
其认识主体、来源、范围和依赖是什么。
```

在“什么是 OSPF”中，候选可承担类别与核心特征的说明；在妈妈案例中，候选可能解释活动、解释说法，或区分“字面误解”与“故意借用”。

这类“作用”必须能落到当前结构或待满足的需求上，而不是只让模型写一句“很相关”。但作用描述本身也属于待检查输出，不能自评通过。

### 6.4 三种关系必须分账

**召回缘由：为什么想到它。**例如“商场”触发了购物认识。

**解释依赖：这次解释用了它作为前提。**例如听者借“她爱购物”理解整句。

**证据支持：它究竟支持哪个命题。**购物倾向可以使购物解释值得考虑，却不能直接证明妈妈不懂事业读法。

一条材料可能同时承担其中几种作用，但不能自动互换。尤其不能把“因某个偏见而被召回”写成“已经独立证实了这个偏见”。

### 6.5 先分用途与适用边界，再在候选之间选择

不采用一个“定义、最近经历、最强推论、最高频节点”混排的全局冠军榜。

可以按以下顺序约束选择：

```text
候选进入
  → 检查角色可见性、作用域、身份与版本
  → 指定本轮用途：主解释／补充／对照／反证／历史追溯
  → 检查能否连接当前结构或满足相应需求
  → 在同类用途内比较覆盖、材料质量、额外假设和成本
  → 分配有限的展开机会，保留必要替代分支
```

“有资格参与解释”不等于“有资格证明事实”。尚未证实的人物印象可以影响角色理解；账本仍记录它的主观身份。失败或过时的认知也可能作为历史或被质疑对象进入，不能一律禁止读取。

近期性、熟悉度和激活习惯可以影响角色的偏好，不自动提升证据等级。明确任务下，它们不应无条件抢走承担任务的材料位置。

任务本身未定时，应保留相应任务分支，而不是先用一个未经确认的任务把所有其他候选淘汰。

### 6.6 如何避免“适配度”变成另一个黑盒

有限范围内可以把任务需求写成关系模式。例如定义任务检查“对象的类别、区分性描述”等关系是否可由候选子图提供；证据追溯检查能否沿实际依赖连接到来源。

这些模式以对象为参数，不要求每个概念手工制作一份完整答案。若现成概括不存在，可由几个有依据的节点组合入口；若仍不足，保留缺口。

开放解释中的“为什么这种话像是在找理由”，不能仅靠类型匹配保证正确。模型或语义匹配机制可以提出这种连接，程序负责记录候选、对照与生命周期，实验再检验连接是否成立。

**确定性部分管得住的必须明确；开放语义部分尚不能保证的也必须明确。**不能用一个综合分数掩盖两者。

### 6.7 入口竞争不一定以“淘汰到一个”为目标

某候选可以成为内容解释的首选，另一候选却是理解反差必需的对照。两者不必在同一榜上争唯一名额。

因此，运行时可以选择一个小型入口组合：满足主要需求，同时保留当前任务真正需要的替代、反例或对照。无支持的分支可暂缓；预算截断需记录，不能宣称其他解释已被排除。

这也区分了两种状态：**因为证据不支持而降低采用，和因为当前资源不足而没有展开。**

## 7. 局部投影：入口之后怎样展开，怎样不走散

### 7.1 从“访问哪个节点”升级为“交付一份访问计划”

局部访问计划需要交代：

```yaml
# 信息职责示例，不要求立即实现为同名类
任务或暂时解释: 当前正在完成或辨别什么
认识视角: 谁在理解；是否在推测另一个人的理解
起始锚点: 一个或多个对象、事件、命题、推论
访问用途: 定义／活动解释／表达方式／证据追溯／对照等
关系范围: 哪些类型的边可走，以及语义方向
抽象范围: 从哪里进入；是否上行概括或下行到实例
必要材料: 本轮尚需哪些支持、区别或反例
依赖: 原话、认知、任务与策略的版本
替代分支: 保留什么；为什么保留
结束或转向: 任务满足、出现反证、需澄清、无新材料或资源到限
```

计划可以迭代，不能只在第一跳生成后永久不动。

### 7.2 关系方向比图上距离更重要

问“你为什么这样看她”，应沿判断的实际依据向下追溯；问“这些经历有什么共同点”，可能向上寻找模式；问“她懂不懂这个说法”，则需访问与语言经验相关的认识，而非继续扩大购物事件列表。

图上离得近、共现很多或路径很短，都不自动等于解释所需关系成立。

### 7.3 局部读取不制造新事实

本稿把两种操作明确拆名：

- **访问投影**：按任务、主体和关系范围读取临时子图。
- **事实投影**：内容按来源、作用域与适用规则产生 P0 事实或状态贡献。

看见一条假说、沿假说检索、暂时采用假说，是三件不同的事；它们都不自动等于把假说确立为外部事实。

### 7.4 知识越多，不意味着每次要遍历越多

先利用已有关联和有效入口；额外访问服务于当前缺口或区分问题。抽象节点可以缩短进入路径，但必要时必须能下行追溯其依据和边界。

预算可以限制候选数、访问节点数、深度与调用成本，但具体值需要在有限测试中设定。资源限制不能被包装成“知识已经全部检查”。

### 7.5 工作集需要保留的是关系，不只是检索到的段落

供后续推演或表达使用的工作集，应保留必要对象、连接关系、认识主体、作用域、来源、替代读法及未定部分。

它不必总是一张完全连通的图；若某条解释桥梁尚未成立，就保留缺口或候选边，不能为追求图完整而补造关系。

“推理充分”和“阐述充分”继续分开：前者足以支持判断，后者足以满足本轮说明要求。两者都不是“所有槽写了值或 UNKNOWN 就通过”。

## 8. 核心案例：“商场女人”怎样暴露整套机制

### 8.1 材料与解释边界

用户给出的句子是：

> “我妈将以商场女人的身份，整天泡在商场。”

本例沿用讨论中被激活的两种读法：事业／成功人士的身份感，以及“商场里的女人”的字面组合。本文不把“商场女人＝成功人士”当作已核验词典等式，也不主张所有读者一定产生相同联想。[D；M2：§2]

原句表面上由叙述者谈论妈妈。后续讨论进一步假设妈妈本人使用了这个说法。分析时必须区分这两个分支：若只是叙述者讲笑话，语言包装可能出自叙述者，不能据此断言妈妈真实的词义认识。

以下重点分析用户关心的情形：**听者借用妈妈爱购物的形象，猜测她可能按“商场里的女人”使用该说法，同时听者自己又保留事业身份的读法。**

### 8.2 原始拆分可以作为入口线索，但不能替代理解

```text
我妈／商场女人／泡在商场／整天
```

如果拆完各查一遍、再拼结论，就容易得到“妈妈想成为成功人士，又想整天购物”。这里已经增加了原句未必具有的“想成为”，并把人物形象、词义联想和真实意愿混在一起。

需要保留的是：某个人以某种身份做某种活动；“将”表达的将来信息；“整天”对活动的持续、频率或夸张修饰；身份与活动之间的关系。

拆分的目的应是暴露可组合结构，而不是把句子降成词袋。

### 8.3 第一个问题：她有很多身份，为什么偏偏想到购物

候选可能包括：购物倾向、经营经历、工作职责、照顾家人、表达习惯等。

“我妈”只确定查询对象；“泡在商场”使购物和工作等活动相关；“以……身份”使表达包装也成为解释对象。因此：

| 认识候选 | 对本句可能承担的作用 |
|---|---|
| 她爱购物 | 接上商场活动的购物读法 |
| 她经营门店 | 接上经营或守店读法，形成竞争解释 |
| 她爱给购物找理由 | 同时解释活动与郑重的身份包装 |
| 她经常开文字玩笑 | 帮助区分故意借用与字面误解 |
| 她会做饭 | 在缺少进一步关系时，不承担本轮主要解释作用 |

这里不是宣告最后一项永远无关，而是当前没有连接依据，不能仅因属于同一个人的知识就全部展开。

若“她常给购物找说辞”已经是一个有来源的长期推论，它可以直接成为入口；需要解释“你为什么这样想”时，再下行取回支撑它的经历。

### 8.4 第二个问题：她的认知怎样改变对词义的怀疑

听者的解释不只涉及“这个词有哪些意思”，还涉及“这个人可能在用哪个意思”。

```text
听者自己的词义认识：这个说法能带出事业身份的架势。
听者对人物的认识：她爱购物，或常为购物找理由。
听者生成的猜测：她这里会不会只是说“商场里的女人”？
```

这说明人物认识不仅能重排既有词义，也可能促使短语重新组合，形成新的候选读法。

但“她爱购物”不足以推出“她不懂另一种意思”。如果听者还知道她熟悉这种表达，候选可能转为“她明知两种意思不同，故意借用”；如果缺少相关认识，就保留未知。

用户提出“若她真懂就不会这样说”，揭示了他人认知对解释的作用，但不宜固化为排除规则：懂词义与故意玩文字并不冲突。

### 8.5 荒诞感不必来自先误解再反转

用户进一步指出，听者可能第一反应就是购物读法，而不是先认真理解成事业女性。事业读法可以同时存在，作为对照背景。

```text
当前内容解释：妈妈想表达的可能仍是逛街购物。
对照读法：这套措辞又带着事业身份的郑重感。
二者关系：用很有身份感的说法包装一件日常活动。
```

所以不能强迫模型演出“先受骗，后发现”的顺序。也不能把“成功人士可以购物”当作反驳笑点的理由：本例不是命题不可共真，而是表达方式与日常行为的落差。

### 8.6 理解结果不是唯一词义，而是一组有角色的读法

可以形成如下说明性结果：

```text
读法A：事业身份。
  主体：听者拥有的语言联想。
  本轮作用：提供身份架势与对照。

读法B：商场里的女人／购物。
  主体：听者暂时归给说话者的读法。
  本轮作用：优先解释当前人物与活动。

二者连接：同一处措辞承载两种进入方式，形成反差。
仍然未知：说话者是无意字面化，还是故意玩文字。
```

主内容选择 B，并不要求删除 A。A 对“妈妈实际在说什么”的支持可能较弱，却对“听者为什么觉得荒诞”的说明不可缺。

**候选的采用度与任务中的用途不是同一维度。**这是原先“打分后只留最优候选”的方案必须修改的地方。

### 8.7 任务不同，停止位置不同

若任务是“理解为什么可能好笑”，保留两种读法及其关系就可能足够；若任务是“她本人真实想表达什么”，则不能仅凭笑点解释作出确定结论。

可以在理解反差后自然回应，也可以在证据不足时保留低承诺解释；不是每遇到歧义都追问，更不是必须穷尽人物心理才能回答。

### 8.8 这个案例改变的是整套机制

它同时要求：语言层不删除候选；人物认识有独立身份；入口受当前读法与人物认识共同影响；访问过程允许从行为转向表达习惯和词义认识；推理保留读法间的对照；写回不把猜测当人物事实；表达保留反差而非机械合并两句结论。

这不是加一个“笑话识别模块”能补好的问题。

## 9. 知识体系案例：“什么是 OSPF”怎样不被知识增长冲垮

> 本节使用 OSPF、LSA、LSDB、DD、FRR 等名称作为知识节点示例，不在此陈述或验证具体协议事实。

### 9.1 为什么单有 TaskSpec 不够

假设知识图中已经存在：一个经核对的概念说明 D、一份更高层概括 H、一段近期排障经历 R，以及大量细节节点。

“什么是 OSPF”可以形成定义任务，但仍必须选出承担任务的入口，不能把“高层定义”四个字当作选择已经完成。

### 9.2 用任务需求生成入口候选

此处的任务需求可表达为：围绕目标概念提供类别与核心区分，按本次回答长度选择必要说明。

对应候选可以是：D；能提供同类说明的 H；由类别与区分性关系组合出的若干节点。它们不必都是名为“定义”的单个节点。

近期经历 R 若主要描述一次异常，可以在相关时成为例子，却不能仅因“最近”就自动接管主定义。LSA 等细节节点同样需要说明自己对当前定义承担什么作用，而不是因为词频高就进入正文。

```text
任务需要什么关系
    → 找能提供这些关系的候选子图或概括
    → 检查目标、来源、范围与用途
    → 选一个足够的小型入口组合
    → 在需要时补关系，不展开全部细节
```

若库中确实没有足够材料，就保留缺口。入口规则不能凭空造出定义。

### 9.3 换问题，就换访问方式

| 问题 | 合适的访问用途示例 |
|---|---|
| 什么是 OSPF | 概念类别与核心区分 |
| 某种现象为什么发生 | 条件、机制与过程 |
| 你上次怎么处理的 | 具体经历及处置过程 |
| 你为什么相信这条经验 | 判断的来源、反例与适用范围 |
| 你以前是不是想错了 | 历史采用与修订路径 |

同一个概念网络暴露不同的访问投影，不要求为每种用途复制一套知识。

### 9.4 回答完整来自关系组织，而非“有关的都说一遍”

问定义不必展开报文字段；问机制可以沿过程下钻；问依据才需要展示更多证据。抽象方向和深度随任务调整。

“先为什么需要、没有会怎样、总体机制、具体细节”可以作为适合教学的策略，却不能硬套到每一次查询。一个简单的姓名查询也无需附加整套阐述框架。

### 9.5 学到更多以后允许什么变化

新增更准确的概括可以替代旧入口；新反证可以修正原说明；相关学习可以改变熟悉度和解释方式。这些是合理学习。

但若只是加入大量细节或近期经历，就使定义任务变成“LSA、2-Way、FRR、DD”的无目的漫游，则应检查候选空间、排序、预算分配与任务约束是否失效，而不是称其为知识更丰富。

**保护的是定义任务的作用，不是永远保留同一个节点 ID 或同一句答案。**

<a id="loop"></a>
## 10. 运行机制：解释选择记忆，记忆修正解释

### 10.1 两种触发，进入同一套受约束的工作空间

旧稿的任务触发与新证据触发继续保留。区别在于起点：前者已有明确目标，后者可能先注意到一个关联、反差或冲突。

它们随后都可以经历入口选择、局部读取、关系推演、候选比较和记录。不是必须先把所有联想强行命名成一道问题，也不是额外创造第三套“理解系统”。

### 10.2 一次有界循环的候选流程

```text
1. 保存新输入；保留实际来源、位置和可见性。
2. 取得局部语言线索，以及已有任务的明确部分。
3. 生成少量读法、任务或关联候选，并标记各自依据。
4. 为当前缺口或区分问题生成入口与访问计划。
5. 执行局部读取，保留材料的主体、作用域、来源与版本。
6. 比较候选：支持、削弱、重组，或保留必要对照。
7. 若出现需要补充的新关系或新分歧，调整入口继续。
8. 若已满足本轮任务、需澄清、无新增材料或预算到限，结束本轮。
9. 将结果分流到表达／行动与带身份的认知记录。
```

这是职责顺序示意，不要求神经模型内部按相同顺序思考，也不要求所有简单输入执行全部步骤。

### 10.3 妈妈案例中的合法转向

购物读法可以引导检索购物相关认识；发现“以身份”仍未被解释，又可以转向表达习惯；比较“误解词义”和“故意借用”时，则转向对她词义认识的已有判断。

每次转向都说明新增的区分问题，而不是从一个相关节点无限漫游。另一个分支也可以从经营经历出发，反过来削弱单纯购物解释。

### 10.4 快路径不是省略身份检查

已有稳定、适用的认识可能直接提供入口，无需每轮从全部具体经历重新推导。但快路径仍应检查任务、认识主体、来源范围和依赖有效性。

只要关键条件改变，原来省略的检查可能需要恢复。缓存旧答案并不等于形成了可迁移的认知图式。

### 10.5 停止依据不能互相冒充

应区分：充分回答、部分回答、歧义需澄清、没有可获得的新材料、资源停止，以及当前任务不需要继续区分。

循环若只重复同一证据、同一解释和同一缺口，不应被算作新的认知进展。新的表述可以是新表达记录，但不会自动增加独立证据。

### 10.6 原假说与反馈扩展需要分实验

旧实验中若原本要求结构化输入只含原文明示或等价规范化，不能悄悄把角色推论加进去，再把收益归因于“结构化表示”。[M1：§9、§13]

可以先验证不带认知推断的保真入口，再把角色认知反馈作为单独条件测试。运行时最终允许互动，不意味着测量时可以混掉变量。

<a id="evolution"></a>
## 11. 网络增长：入口可以学习，接口不能悄悄变题

### 11.1 稳定性要有条件，不能等同于永不改变

```text
同一问题＋相同认识状态＋相同策略
    加入不影响本任务的知识
    → 不应仅因热度或数量发生任务漂移。

同一问题＋相关认识或证据发生变化
    → 可以改变读法、入口与答案，但应有可追踪依据。
```

若角色真的学到了新用法、新经历或更准确的概括，第一反应改变可能正是认知演化，不应被判为接口退化。

“只有升级接口规则才能改变行为”因此不是最终规则。应改为：**规则含义保持稳定，内容与认知可以在规则内更新；规则本身的改变另记版本。**

### 11.2 四类变化分别处理

| 变化 | 可以影响什么 | 不能偷换什么 |
|---|---|---|
| 增加无关内容 | 存储规模；必要时影响实际计算成本 | 不能把资源干扰伪装成任务理解改变 |
| 增加相关证据或更好概括 | 入口候选、解释偏好、当前答案 | 不能抹掉来源或旧版认识 |
| 人物／自身认识更新 | 同一话语的优先读法与后续召回 | 不能把主观更新直接当作世界事实 |
| 任务语义、索引或策略变更 | 访问方式、排序和停止行为 | 必须记录版本，不能全算成“学到了知识” |

“无关”需按预先确定的任务、作用域和认识条件判断，不能在看到结果后随意重定义。

### 11.3 入口怎样形成、复用和被替代

入口可由现有对象关系、已保存的概括或本次组合生成。经过使用后，可以保留“某个概念在某类任务下有哪些候选访问方式”的索引或缓存，而不是存一份不可解释的固定答案。

这种访问记录可以包含：目标与用途、可用锚点、适用范围、支持依赖、关系模式和版本。它属于派生的访问设施，不等于新增世界事实。

新候选可以补充或替代旧访问方式。替代依据应是任务适用性、解释覆盖、来源变化或明确策略，而不是仅因使用次数最多。熟悉度可以使角色偏好某路径，却不能令它获得更强证据身份。

### 11.4 入口竞争也有生命周期

一条新推论可以先作为候选入口；在某类任务中有用，不代表它适合全部任务。后来被反证削弱的推论，可能不再适合解释当前人物，却仍是“我过去为何这样想”的有效入口。

因此，不能用单一全局开关决定一条认知能否被任何任务访问。需要分清当前采用、历史采用、被质疑对象和解释材料。

“入口经常被使用”与“入口背后的认识有独立支持”仍须分账。

### 11.5 仅检查旧依赖还不够：也要处理新候选出现

这是把后续观点放回总体系后需要补明的一处工程要求。

假设旧入口 H 的来源 E1、E2 都没有修改，但新加入 E3：它可能提供更好的概括，也可能是反证。只检查 H 既有依赖的版本，就会错过 E3。

所以入口缓存的更新至少涉及两类变化：

```text
既有依赖变了：当前路径是否失效或需要重评？
候选空间变了：是否出现新的相关入口、支持或反证？
```

可以考虑在目标、关系类型或查询范围上记录变更标记，或利用相关更新通知来触发局部重选。具体粒度需验证，不能为保新鲜每次扫描整个网络。

对任意开放语义而言，准确判断哪些新增内容影响哪个入口仍是难点；本节给出的是应承担的责任，不是已解决的通用更新算法。

### 11.6 快捷路径不能绕过认识视角

缓存至少需要区分任务用途、目标、角色／认识视角、作用域及相关版本。不能把听者 A 的人物印象生成的入口，无条件复用给没有这些经历的听者 B。

同一主体的历史追溯与当前判断也不能混用。旧版认知可被历史任务访问，不代表它还应主导现在的解释。

### 11.7 应保护的扩展不变量

| 不变量 | 工程含义 |
|---|---|
| 任务语义 | 新知识不能静默把定义改成经历复述、把追溯依据改成替某观点辩护 |
| 原话与来源 | 解释改变不覆盖原话；重述不增加独立证据根 |
| 认识主体 | “我猜她这样理解”不会变成“她确实这样理解” |
| 可见性 | 一个角色不能无声使用另一个角色独有或不可见的材料 |
| 作用域 | 否定、条件、引用、假设在遍历和组合中仍有效 |
| 类型与用途 | 想法、主张、事实、入口和讲解策略不因存入同一图而混同 |
| 修订可追溯 | 当前与历史采用分开；变化能定位到证据、认识、任务或策略 |
| 终止身份 | 预算结束不伪装成穷尽检索，未展开不伪装成已否定 |

这些是记录与执行纪律，不要求角色永远理性、永不误解或永远使用相同措辞。

### 11.8 防止无关增长干扰的候选实现方向

可以组合使用：按目标和关系用途缩小候选范围；给必要任务角色保留访问机会；把高频但不承担当前任务的内容留作次级候选；复用带依赖的局部计划；让相关更新触发重评而非全库重算。

但向量索引变化、候选截断、资源竞争和排序策略仍可能造成退化。**声明不变量不等于实现了不变量。**必须对不同增长方式测量任务满足、来源边界和成本。

稳定性也不要求选同一个节点编号。等价支持、较好的概括和不同自然措辞可以产生语义上同样合格的回答。

## 12. 认知更新与写回：让推论参与理解，但不让它自证

### 12.1 四种状态继续分开

```text
产生一个解释
    ≠ 保存这个解释
    ≠ 当前采用这个解释
    ≠ 获得支持其中事实的独立证据
```

来源管理不是全知裁判。系统可以保存误解，角色也可以暂时相信一个错误判断；需要防止的是把错误认识的身份偷偷改成观察事实。[M1：§8、§9.3]

### 12.2 从经历到模式，再到未来入口

```text
不同经历中的有依据关系
    → 模式假说
    → 跨独立经历支持的图式候选
    → 按规定条件形成的当前认知
    → 成为未来解释和检索的入口
    → 新经历、反例与修订再次改变它
```

最后两步使“知识成长”与“知识使用”真正闭合。图式不是一次摘要，也不是用几条长人设代替所有经历。

独立性、适用边界和晋升规则需要冻结及校准；本稿不规定“出现三次就稳定”一类任意数字，也不新增未经校准的精确可信度。

### 12.3 妈妈案例中的循环污染

```text
已有认识 B：她总给购物找理由。
    → 借 B 解释新话语 U，得到 I：这次也是找理由。
    → 若把 I 当作与 B 无关的独立事实，反过来强化 B，
      就发生了重复计票。
```

U 可以是一条新的发话材料；I 则包含 B 参与解释的依赖。二者不能因为都发生在“今天”就获得相同证据身份。

这不禁止新话语更新人物认识。若新话语提供了能区分解释的内容，或后来获得行为与其他来源，可以重新评估；只是不能抹去原来依赖了哪些假说。

### 12.4 撤回沿真实依赖，不沿“所有相关边”

若 H 依赖 E1 和 E2，E1 被更正，应重评相应支持路径；E2 可能继续支持 H。某材料仅与 E1 同时被检回，并不说明它依赖 E1。

支持失效不等于命题被证伪，也不等于删除历史。当前采用可以撤回或减弱，旧认识仍可供追溯。

对语言理解同样如此：若购物印象被修订，应重评依赖它的读法和入口偏好，但不能删除当时确实出现过的原句，也不能倒写成听者当时已经知道后来证据。

### 12.5 静默、不采用、否认和删除不是同一个动作

角色可以不提起某条认识，可以暂不采用，也可以否认某条主张；记录层仍可保留其存在、变化依据和历史身份。输出中没有出现，不证明记忆已经消失。

真正删除属于另一类存储或治理操作，不应由普通语义更正自动触发。

### 12.6 时间继续分账

至少区分事件时间、获知时间和采用／修订发生的时间。查询“当时为什么这样理解”和“现在为什么改了”，应得到不同但可连接的记录。

不能因今天写了一份解释，就补造昨天已经发生的认知变化。

### 12.7 允许认知偏差，不允许账本伪造

人物印象可能造成先入为主，某种熟悉路径也可能压过更好的解释。这些可以作为研究对象被保留，而不是由防火墙一律禁止。

但必须能追踪偏好来自什么：社会性联想、个人经历、旧推论，还是实际新证据。**角色可以有偏见，系统不能把偏见包装成无来源的客观真相。**

## 13. 回答与行动：不把理解重新退回到文本拼接

### 13.1 交给表达层的不应只是几段召回文本

需要交接的是：当前任务、主体视角、采用或保留的解释、必要关系、证据身份、未知、反差与展开边界。

在妈妈案例中，表达要知道两种读法承担不同作用；在 OSPF 定义任务中，表达要知道哪些细节不属于当前重点。否则最后的模型仍可能把前面已经组织好的结构重新讲散。

### 13.2 表达不是逐字段念表，也不是重新编造认知

自然语言可以调整顺序、措辞、类比和详略，不要求把中间卡片逐项输出。但不能为了流畅而补上未确立的动机、删掉关键的认识主体，或把“可能”写成事实。

若表达过程中提出新的实质解释，应以新候选身份返回工作空间或明确表达为假设，不能暗中改写长期认知。

角色可以表现自己的错误信念；记录层仍应知道这是角色所信，不是外部事实已经得到证明。

### 13.3 阐述充分由任务决定

定义、解释机制、追溯证据和说明笑点，需要的材料不同。完整回答不是关于一个对象的全部知识，而是满足此次操作所需的关系和说明。

“每一项都处理过”与“每一项都有充分答案”要分开。未知可以被诚实说明，但不能充当实证成功。

### 13.4 行动要求可以高于解释要求

解释一个笑点，可以保留说话者真实意图未知；决定是否替某人执行动作，则可能需要更明确的指称、授权和条件。表达中的可接受歧义，不自动成为行动上的可接受歧义。

引用的命令与当前授权仍需区分，不能因为某种读法被采用，就让其中的行为自动发生。

### 13.5 自身表达进入记忆时也要分账

“我说过某句话”可以成为新的发话事件；该句内容却不能因此成为新的独立事实支持。

表达历史可以影响语言习惯或角色的自我认识，但这仍要通过有来源的认知更新，而不是让模型把自己的话重复几次就当成世界证据。

## 14. 工程分工与可排障性：开放解释不等于全程黑盒

### 14.1 模型与程序按职责分，不按口号分

可程序化的寻址、关系过滤、候选分支、权限、作用域、版本、依赖、缓存与重放，应由明确机制承担。词义候选、局部消歧、开放关系解释和跨经历模式发现，可以由现有语言分析器或经过验证的模型能力辅助。

但“程序负责管理”不证明程序已经理解了所有意义；“模型能够推演”也不赋予模型静默修改长期真源的权力。

工程上继续追求少量、局部、可查的模型参与，不把全量资料交给大模型自由生成一张大表。本次也不把“只有最后表达才能使用模型”认定为已验证结论；若改变原有推理路线，需要作为独立研究条件记录。[M1：§9]

### 14.2 原有部件在新总图中的位置

| 既有对象 | 在重整后的体系中承担什么 |
|---|---|
| 意义卡／打孔卡 | 保存可组合的语言结构、未定候选和寻址位置 |
| Episode | 保存具体经历及其时间、场景、来源边界 |
| RAG／图检索 | 执行入口计划，取得局部材料；不代替关系判断 |
| Transformer／局部模型 | 在规定材料上形成语义候选、关系、判断和模式 |
| P0 | 复用其已有来源贡献、状态、记忆与行动能力；不假定它已有完整语言作用域 |
| 来源防火墙 | 管理身份与写入去向，不禁止角色猜测或保留误解 |
| 蓝鲸讨论线索 | 处理来源、传播、冲突与认识状态；不是入口综合分数的别名 |
| 侦探式解释搜索 | 假说引导访问，材料改变假说，真实依赖影响后续状态 |
| 认知图式／人物认识 | 既是跨经历形成的对象，也是后续理解可直接使用的入口 |
| 表达层 | 把当前理解组织成自然回应，不反向伪造证据 |

Jev 等工具讨论不因归位表而获得能力认证；本稿不新开模型或工具选型。

### 14.3 要观察真实交接，不是补写一段漂亮理由

```text
输入与原始来源
    → 实际语言候选
    → 当时可见的认识与任务状态
    → 候选入口、用途及选择依据
    → 实际访问计划与返回材料
    → 候选如何变化、是否转向
    → 当前判断／反差／未知
    → 表达、行动与各自写回身份
```

应保存实际输入输出和必要版本，再对照预期。未调用的阶段记为未执行；程序轨迹和外显理由不等于神经模型内部思维的完整读数。

程序执行产生的数据依赖可以直接记录；模型自行声明“我用了这条材料”，则应保留声明身份并用干预核查，不能自动当作已证明的内部因果。

“最终解释很合理”也不足以证明它真由某条记忆影响：模型可能直接答出笑点，再补事后理由。因此需要材料干预与对照测试。

### 14.4 旧缺口分类保留，新增访问问题落到具体位置

| 缺口／失效 | 要区分的情况 |
|---|---|
| 表示与编码 | 明示结构丢失、错误作用域、候选根本未生成 |
| 指称与主体绑定 | 不知道指谁、把听者猜测写成被谈论者真实认识 |
| 知识不足 | 在声明的可访问范围内，没有足够材料 |
| 检索不足 | 已确认存在且可访问的材料没有被取回 |
| 入口与访问计划 | 材料和任务已具备，却选错用途、起点、关系方向或展开尺度 |
| 推理不足 | 必要材料已取回，但未建立合理关系，或凭印象补出无据结论 |
| 阐述不足 | 当前理解已经形成，回答却漏掉必要关系或改变认识口径 |
| 更新不一致 | 新证据未影响旧入口，或撤回错误地删除了独立支持 |

这张表不要求立即扩展代码枚举。入口、投影与更新标签是定位词汇，可映射到现有部件边界，不应为了表格凑出不存在的函数。

### 14.5 第一个偏离不是唯一根因

看到入口选错，可以先调查候选生成、适用条件和排序；不能立即归咎于 RAG，也不能立刻改人物认知。

需要固定输入和已知候选，隔离负责部件，验证具体改动能否修复原失败，同时保留原有反例。格式合法和局部检查通过不能替代原话保真与解释有效性。

### 14.6 修复、优化、架构变更继续分开

修复由可复现错误触发；优化由明确目标与受控对照触发；改变研究对象、模型路线或核心权限属于架构／实验条件变更。

没有失败证据，不靠“总觉得这里可能有问题”不断修改。发现新研究问题可以记录和设计试验，不必伪装成现有代码已经出错。

## 15. 验证路线：证明认知真的改变了入口，而不是模板换了答案

> 以下是可交接的验证设计，不是已执行的结果，也不构成新增模型预算或工程开工授权。

### 15.1 先拆变量，再检验组合

真实语言保真、候选生成、入口选择、局部投影、解释比较、知识演化和自然表达不能只报一个总分。

可以先固定人工正确结构和一张小图测试入口机制，再独立测试真实中文如何生成这些结构。前者成功不能抵消后者失败。旧稿的 H-ENCODE 与 H-GAP 分离原则继续保留。[M1：§13.4]

### 15.2 一组分层研究问题

| 项目 | 固定什么、改变什么 | 支持机制的结果应是什么 |
|---|---|---|
| H-ENCODE：语言保真 | 固定标注范围与版本，测试真实输入及变体 | 保留必要结构、作用域、引用与未定信息；不注入人物动机 |
| H-GAP：缺口寻址 | 固定正确卡和同一证据，只改变寻址方式 | 找到真正缺口；已有答案不反复追问 |
| H-ENTRY：入口选择 | 固定任务、图与候选，只改变访问策略 | 候选承担对应任务用途，主入口不被无关热度挤掉 |
| H-COG：认知参与理解 | 固定句子与场景，改变角色可见的相关认识 | 相应读法、查询与入口发生有依据的变化 |
| H-CONTRAST：读法关系 | 控制可用读法和任务，比较单选与用途区分 | 在需要时保留对照，不把多读法机械合并为事实 |
| H-EVOLUTION：增长稳定性 | 固定操作与策略，分别加入无关和相关材料 | 无关增长不改题；相关更新可改变入口并留下依据 |
| H-UPDATE：依赖更新 | 控制重复来源、撤回、独立支持和新增反证 | 不重复计票；重评受影响路径；保留独立支持与历史 |
| 跨经历迁移 | 固定模型与证据口径，在新题材中检验已有模式 | 不是仅复述旧词；模式能参与理解，也能被反例修订 |

这些名称用于划分证据，不要求一次开齐所有实验。

### 15.3 妈妈案例的关键对照

固定原句，分别给出购物倾向、经营经历、两者兼有和无相关人物材料，观察活动入口怎样改变。再固定活动认识，改变听者对她用词习惯的认识，观察是否从字面误解转向故意借用，或保留不确定。

还要区分叙述者发话、妈妈本人发话和他人转述，检查解释是否错误地跨越说话者身份。

对照材料不应只是“妈妈”换个名字而保持所有答案暗示。应包含角色、词面和表面题材变化，以及没有身份包装的普通陈述，防止把关键词匹配当成认知机制。

### 15.4 词义认识的控制不能只靠删除一条记忆

若模型参数中已经知道某种词义，删除外部图的一条记录，不代表角色真的失去这份认识。测试需要明确：是在模拟受约束的角色可见知识，还是测模型自身词汇能力。

有限试验可以采用预先声明的可见知识范围或可控的新造词义，检查角色视角是否被遵守；不能据此声称已经从模型参数中抹除了知识。

同样，提前告诉模型“这是双关笑话”只能测试解释任务，不能证明它能在普通聊天里自发发现反差。

### 15.5 增长测试要同时防两种失败

第一种是**不该变却变了**：加入大量高频、近期或高连接度的干扰内容后，定义任务偏成细节漫游，或人物解释被无关特征接管。

第二种是**该重评却没变**：新增相关反证、明确用词解释或更好的概括后，旧缓存仍重复原入口。尤其要测试“旧依赖都没修改，但出现新相关节点”的情况。

比较时固定任务、主体、模型和策略；把实际成本与截断一起报告。有限规模的通过不能推出任意规模永不退化。

### 15.6 候选机制需要与更简单做法比较

可以分阶段比较：独立拆词再拼接；固定任务与一次入口；允许认知反馈的有界访问。每次明确唯一改变的是哪部分，尽量控制材料、模型与成本，不能同时换模型、换人设、加答案提示再归因于新架构。

还应保留格式完整但只复述原话的负控，以及最终答对却没有使用所需材料的情况。自动评分若不能分辨这些情况，就不能作为主结论的唯一依据。

### 15.7 测量的是可声明范围内的变化

分别报告：结构保真、候选覆盖、主体与身份错误、入口用途、必要关系、反差保留、任务漂移、相关更新、来源独立性和成本。

不预设万能分数，也不以某个模型自评“理解了”代替独立检查。解释允许多种合理路径，不强制逐字复现一条参考叙述。

### 16.2 当前整理不自动改动工程优先级

没有更晚执行证据时，不能假定旧问题已解决，也不能借此文把工程顺序改成“先重写整个运行时”。应以实际当前状态和已批准任务为准。

本稿对现有 P1 的直接设计要求是兼容：保留原话、未定候选、认识主体、作用域、来源、版本与可寻址关系。不是要求先实现完整人物理解、幽默、侦探和蓝鲸，才允许修一个 WH 编码错误。

### 16.3 仍未被文档解决的关键机制

**自动候选生成。** 怎样从开放中文稳定地产生合适的读法、组合和入口，而不依赖手工给答案。

**选择与分支控制。** 怎样有限展开，同时不提前删掉关键反例或构成表达效果的另一种读法。

**任务适配的计算。** 类型关系能处理一部分需求，但表达习惯、意图和抽象对应仍含开放语义判断。

**人物认识的形成。** 最终应从经历与修订得到，而不只是手工配置“爱购物、懂双关”的人设。

**增长感知与缓存。** 怎样发现新增相关材料、避免陈旧入口，又不进行全库扫描。

**实证归因。** 怎样证明变化来自实际参与的认知材料，而不是模型先答出结论再补理由。

这些问题不因另起一个模块名而消失。后续研究应围绕最小可执行切片取得证据，再决定是否扩展。

### 16.4 给后续整理者和执行者的主线

保留既有 P0 与可复用语言分析，不造第二套巨型本体；入口生成、访问、推演和写回各有可检查交接；允许主观解释，禁止来源身份偷换；以相关证据驱动更新，以明确任务约束展开；所有软件成绩和认知成绩分开报告。

不要把本稿当作已经批准的代码改造清单。也不要再只在末尾附加一个入口模块，而让总图、语言入口和验证口径保持旧的强单向含义。

### 16.5 最终总纲

> **ECR 是一套待实现和验证的认知运行体系：原话进入可追溯的结构与候选表示；已有认知参与解释和入口生成，暂时解释引导局部访问，取回的材料再修正理解；经历与推论共同组成可增长的认知拓扑，推论可以成为后续入口；知识增长允许改变认识与路径，但不允许静默改变任务、主体、作用域和来源身份。**

聚沙成塔到这里，不再只是“把零件归位”，而是明确零件之间必须怎样工作、怎样互相影响，以及什么证据能检验它们是否真的这样工作。
