## 开发 Agent 路径选择

**若目标是 DSH 长期记忆磨损问题：**

1. 从 `01` 判断哪些要求属于机械记忆引擎，哪些属于 LLM 的开放判断。
2. `02` 的第一轮只做“带来源的事件／认识记录 → 入口与关联 → 有界激活／传播 → 工作集 → 可回溯召回”，以及历史版本保留。
3. 把侦探和蓝鲸理论中**证据归属、不同解释并存、依赖撤回、旧认识保留**作为约束；暂不开发完整的人格成长或连续自主思维系统。
4. `03` 用于设计角色初始化和新情境评测，不作为第一轮扩大范围的理由。
5. 统一和摘要记忆、纯检索记忆对照。**没有改善就报告失败与边界**；禁止通过优化示例答案或更改测试集冒充机制有效。
6. 这不是要求 Agent 重做既有 ECR 工程，也不意味着历史仓库里的任务与代码已经迁移过来。
