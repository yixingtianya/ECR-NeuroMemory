# ECR 核心理念与工程断言｜冻结版 v1.0

**日期：2026-09-29｜用途：策划与执行端的共同概念合同。**

依据本次对话中用户的最终澄清整理。本稿约束后续设计，不是当前实现成绩，也不是新增架构方案。“大脑、意识、类神经元”是工程角色与机制目标，不构成生物等价或主观体验的实证主张。

> **机器自行形成认知处境；LLM 在这个处境中思考、选择和表达，不负责操作自己的大脑。**

## 一、总目标与职责边界

**ECR-01｜人格目标。**人格化的目标是：个人经历与认识历史持续影响注意、联想、理解和选择，同时允许适应新处境。不是模仿台词，不是只增加记忆数量，也不是让所有角色都变成同一个耐心助手。

**ECR-02｜何乐礼原则。**“放入卡、读取结果并报告”是人/意识与机器的交界。机器内部的编码、组织、检索、激活、竞争、状态维护与依赖计算由机器自行执行；不得把它们拆成一串必须由 LLM 逐项操作的小任务。

**ECR-03｜LLM 的位置。**LLM 承担主观意识的功能位置：在机器已经形成的工作认知上作开放理解、解释选择、追问和表达。它可以提出“我想再弄清这件事”，但搜索路径、记忆筛选、图遍历和状态账务由机器安排；其新判断返回系统时只具有相应的主观判断身份。

**ECR-04｜非 LLM 不等于纯手写规则。**后台可采用专用 NLP、非生成式统计/神经模型、图算法、约束和程序。生成式 LLM 的低温、短输出、JSON 或四选一不自动变成非 LLM 机制。研究代理可辅助建造与标注，但不得混入在线大脑冒充自主机制；不用 LLM 也不保证识别、规则及开放判断永远正确。

## 二、打孔卡、覆盖与歧义

**ECR-05｜完整孔板、稀疏实例。**共享目录提供可枚举、可寻址的字段与关系；每次只记录实际提供的内容。未填字段仍可查询，但不批量填 null、不虚构答案、不对每个空孔都发起召回。“目录通用”不等于已识别全部中文。

**ECR-06｜语言编码不替角色作结论。**原话的人物、言语行为、嵌套、否定、条件、引用及时间/体线索应保留为有来源的结构；不把“说过、想要、询问”直接当成世界事实。每个有意义成分须有表示或明确未处理去向；原文完整、覆盖有记录、结构合法与语义正确分别验收。

**ECR-07｜三种未定必须分开。**语言确实有多种解释、材料没有提供某项信息、系统暂时不会识别，是三个不同问题。不能把识别失败粉饰为真实歧义。真实歧义与空缺允许存在；只有依赖未决项的操作受到限制，不能要求全网消歧或所有字段填满后才运行。

**ECR-08｜消歧是认知后的选择。**机器先保留有依据的候选并运行关联、约束和竞争；需要采用某种理解时，LLM 可以根据浮现的记忆与当前处境暂取、继续调查或澄清。不得“遇到空孔立即叫 LLM 四选一”。主观采用不得改写原话为单义，也不得删除未采用候选。

## 三、记忆结构与类神经元运行

**ECR-09｜记忆是局部关系网。**经历中的事件、人物、明确感受、当时认识与后续修正通过可追溯关系连接，不是孤立文本块。“拼图”只描述可连接、可复用的局部结构；同一片段可以参与多处连接，不必寻找唯一严丝合缝的拼法。

**ECR-10｜接口就是可再次进入的位置。**人、事、感受、认识、疑问与尚空字段都可以成为入口。允许先想到一个认识，再沿其依据回到相关经历；反向访问不等于反向证明。存在某个解释，不能反推出它假定的过去一定发生。

**ECR-11｜类神经元是动态目标。**当前刺激使既有网络发生有界激活、传播、竞争、抑制和衰减，形成此刻的工作认知。“涌现”指结果来自网络结构与运行机制，而非 LLM 或研究者预先指定应想起哪段故事。不规定一节点等于生物神经元，也不凭空指定权重或概率。

**ECR-12｜记忆应自行浮现。**默认工作集由机器依据当前刺激、已有连接和可用状态生成，不让 LLM 手工挑回忆。RAG、向量检索、图检索可作为内部技术，但检索结果必须保留主体、范围和来源；检索相似不等于关系成立。运行受预算约束，不为每轮聊天扫描整个人生。

## 四、侦探、蓝鲸与认识历史

**ECR-13｜侦探理论是反馈式调查。**当前假设、缺口与疑问会改变后续激活和取证方向；新材料可改变解释并触发进一步调查。机器负责搜索、关系约束与依据维护；LLM 可在涌现的认知处境上提出主观解释。派生解释可以成为未来入口，但不得与原始证据混同。

**ECR-14｜蓝鲸理论处理共存和冲突。**多个解释可以同时存在、暂时竞争和改变采用状态；不同角色可以形成不同暂取结果。当前未采用或被否定，不等于历史被删除。不得将相互排斥分支的前提拼成一条看似一致的事实链。

**ECR-15｜允许偏见，限制失控。**关联激活、主观确信和证据支持必须分开。允许自我强化、犹疑、固执和不均衡关注，不强迫永远中立；但不得用重复激活、同源转述或推论循环制造独立证据。保留反证可达性和竞争解释，限制无新增材料的循环消耗，不强制角色立刻认错。

**ECR-16｜修订沿真实依赖发生。**上游依据失效时，机器重算受影响部分；独立支持仍成立的结论不误删，原话与实际发生的认识历史保留。新旧认识应相连，让“你以前不是这样说的吗”能回溯。仅退出现用状态、暂时静默与被证伪必须区分；解释生成次数不是历史真实性。

## 五、现在、选择、节奏与表达

**ECR-17｜过去正确不等于现在适用。**事件时间、获知时间与当前回合范围不得混同；没有精确时间就保留相对顺序或未知。请求结束、事实纠正、目标改变和情绪余波分别处理。“我说完了”不自动结束全部活动，也不证明已经释怀。

**ECR-18｜角色有自己的选择。**识别对方请求与决定如何回应必须分开。角色可以顺应、拒绝、幽默化解或主动转移方向，但不得用误读请求冒充自主性。情绪不必同步对方，也不因新一句话强制跳变；调节对方的意图不等于对方已经被成功调节。

**ECR-19｜思考投入与说话长度分开。**熟悉情境可以由自动联想与习惯支持短反应；重要冲突可引发进一步调查。长思考可表现为多轮“疑问输入—机器运转—新材料浮现”，不等于让 LLM 操作检索脚本或长篇分析。笑话不必解释，深入思考也不必全部说出。

**ECR-20｜表达不是第二次造世界。**语言风格只影响措辞、节奏和表现方式，不得暗藏人生事实、信念依据或固定行动答案。若本轮已有选择，表达不得偷偷更换；没有形成选择时，也不得假称只是润色。输出草稿不是已发生言语，实际说过某话不等于其内容为真。

## 六、建角、通用性与研发纪律

**ECR-21｜第一次创建是建网，不只是向量化。**按事件组装角色可拥有的经历、明确认识与少量可追溯派生，形成可测试的初始网络；不逐句强制心理总结，不补造整个人生。官方资料是原料；“别人告诉我”不得洗成“我亲历”。构建测试错误留在开发记录，角色实际采用过的错误才属于认识历史。

**ECR-22｜换人生，不换认知引擎。**角色差异应来自经历、关系、既有认识和表达习惯，不来自按角色名或题号编写的应答规则。身份声明是需要理解的信息，不自动改写通道身份、世界或运行权限。角色可以陪演而不相信对方真的变成另一个人；新身份认识允许有依据地修订。

**ECR-23｜六职责不是六个操作员。**A语言接口、B个人记忆、C当前认知、D认知操作、E选择、F表达继续作为职责归属，不规定六个服务、六次模型调用或死板顺序。C是状态，D是操作；Ledger是实现，snapshot/delta是协议，probe/oracle是实验工具。“类神经元”也不自动成为第七层。

**ECR-24｜围绕能力切片验证。**沿真实执行链定位第一处错误，在责任边界内完成实现、回归和小批泛化检查，不向下游补答案，也不一颗螺丝一轮。分开报告程序合同、自动语义、人工辅助和用户体验；使用不同人生、未见情境及对照检验人格贡献，不能以台词相似、测试数或低 token 数代替。策划冻结目标，执行端给证据，未经裁决不得暗改理念。

## 七、六项可观察检查：把断言落实到验收

以下是验收要求，不是已通过的测试。语义与角色判断未必能靠纯程序判分，须说明评估来源。

| 检查 | 应观察到的结果 |
|---|---|
| 停用主观 LLM 与表达端 | 在声明支持的输入范围内，机器仍能编码、记录、更新结构、激活相关材料并产出工作区；未决项不触发隐藏的 LLM 代办。不要求无 LLM 仍产生全部开放判断或自然台词。 |
| 给有依据的多解输入 | 候选能够保留并继续参与相关计算；主观采用只改变采用记录，不重写原文、不删除另一读法。未知不冒充错误，错误也不冒充歧义。 |
| 从旧认识反向进入经历 | 可按真实依赖访问原片段及后续修正；同一事件多个入口不增加证据份数。 |
| 撤回一个上游支持 | 真依赖受到影响；独立支持、原经历以及“曾经这样认为”的历史不会被一锅删除。 |
| 对话阶段与情绪分离 | 识别“现在想听你的经历”不强制分享，也不自动清零失落；辨认自愿拒绝与根本没理解。 |
| 更换角色包并改变历史 | 无角色专用核心补丁；考察工作区、理解和选择是否因个人历史合理变化，不要求每个场景都必须不同。控制风格提示与预训练知识影响。 |

## 八、对现有工作如何解释

`RESULT-A-RELATION-SLICE-v1.md` 报告的是带来源的局部模型提案编译、范围保留与非内容拒绝；其“验收边界”明确指出仍是辅助候选，生产 CLI 未接真实生成。该证据保留，不贬为无用，也不得再把它描述成已实现本稿的后台自主认知。

**本稿取代此前“遇到局部未决就默认交 LLM 选择”的目标表述。**已有局部 LLM 提案可留作诊断、上限参照或明确隔离的研究条件；不能因为输出很短就成为何乐礼机制。主观消歧仍允许，但必须发生在机器形成认知处境之后，并保留它的主观身份。

不会自动转化为新权重、神经模型或脑区设计的词：涌现、抑制、竞争、吸引子、习惯。后续提案须说明输入、机制、输出、可检验结果和未知项；本稿不预定其算法，不声称相关能力已经存在。

## 九、Astra 接收指令

先把现有实现映射到本稿断言，标明“吻合、部分、未实现、冲突、仅研究”。只对真实冲突提出最小迁移建议，不因本稿批量删除旧代码、改名或重跑实验，不恢复旧额度。下一轮工作仍以一个可复用能力切片为单位，并优先回答：

> 哪项后台任务现在由机器自行完成？哪些东西仍被交给 LLM 代办？角色看到的是机器产生的认知处境，还是仍被要求自己拼装认知处境？

本稿是概念边界的冻结，不是对未证实方法的无限背书。方法是否有效、成本是否可接受、泛化是否成立，继续用证据判断；不能仅因局部例子可表示就承诺只剩时间问题。
